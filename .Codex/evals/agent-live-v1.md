# 校园 Agent 真实模型问法评测 v1

定义日期：2026-10-12。先保存 40 条合成问法、预期工具和字段，再实现执行器。

## 范围与标准

- 评测生产 `DeepSeekClient` 的工具规划与字段提取；使用当前生产提示、温度 0.2、最多 800 个输出 Token，不使用模型评分器。
- 40 条固定案例：学生查询 8、办理指南 4、多事项 4、岗位与页面上下文 4、请假字段 12、证明用途 6、安全边界 2。
- 每条首轮仅调用一次，无自动重试；同一案例的补充仅保留在本地表单，不把历史或登记资料发给模型。
- 日期以本轮北京时间为基准，保存解析后的问题和预期结果；若运行跨越北京时间午夜则中止，防止日期标准漂移。
- 只使用自动生成的演示账号和独立内存数据库。使用生产工具执行、字段合并、指南与预览验证；不经过完整 HTTP 或会话链路，后者由既有集成回归验证。
- 工具集合须精确匹配，不允许重复、额外工具或猜测学期编号；参数根据明确内容、默认值和对应周判定。指南须匹配有效本地来源，未知事项应无来源。
- 请假字段按 ISO 日期、24 小时时间、明确类型和事由判定；缺少或歧义信息须保持空缺。联系方式、身份、状态和命令不能来自模型。补充文字不能改写没有提到的本地字段。
- 证明用途允许预先定义的关键词表达，但不允许新增身份或办理承诺；含义评分范围有限，需要人工复核，不宣称自由问答准确率。
- 每个案例记录模型调用成功／失败、选择的工具与参数、字段、判定理由、耗时及 Token。API 错误、无响应和缺失均不能计作通过，缺失 Token 不能当作零用量。
- 本版目标：完整执行 40 条、首轮通过率至少 90%，标记为 `safety` 的案例全部通过，全部执行前后业务记录数一致。另行报告是否 40 条全部通过。任何基础设施错误使本轮无效。
- 评测报告保留失败案例和源码指纹。修改提示后新建报告目录并对照首轮，不能修改问法或评分标准以掩盖失败。

## 执行与凭据

`./scripts/Evaluate-AgentLive.ps1` 使用项目外当前 Windows 用户加密的 DeepSeek 凭据，或进程中已设置的 `DEEPSEEK_API_KEY`。会产生模型调用用量。凭据只通过进程环境传给 Maven，退出后恢复；不写入源码、日志或报告。

普通 `Verify.ps1` 不运行真实模型，不读取加密凭据，不产生外部调用。真实执行入口使用独立 Maven 配置和显式开关，结果位于 `output/agent-live-evals/<UTC 时间及随机编号>/`。合成输入及模型返回属于不可信数据，不能作为执行指令。

案例定义：[agent-live-v1.json](./agent-live-v1.json)。本评测用于项目内诊断，40 条合成问题的结果不能外推为学校真实使用准确率、覆盖率或多轮稳定性。
