# 校园 Agent 固定场景回归 v1

定义日期：2026-10-11。基于已实现的查询、请假／证明辅助与 V12 会话恢复，先定义通过标准，再实现执行与报告脚本。

## 目标与通过标准

- 固定 40 项场景，覆盖有效指南、本人查询、字段收集、权限、人工确认、恢复和异常。
- 每项对应一个已有的 Java 集成测试方法，复用真实 HTTP、身份校验、业务服务与独立 H2 数据库中的断言。
- 模型使用受控替身；本次评估工具执行边界与恢复契约，不评价真实 DeepSeek 的自然语言理解准确率。
- 全部 40 项必须执行并通过。跳过、缺失、重复的 JUnit 结果或 Maven 失败都不得被当作通过。
- 不自动重试，不以挑选成功的一次覆盖失败。本版只报告本次首轮结果，不宣称 pass@3 或多次稳定率。
- 输出每类通过数、每项状态、耗时、案例与源码指纹及失败定位；报告不复制问题、表单、登记资料或密钥。
- 每次运行使用新报告目录，禁止读取上一轮 JUnit 结果来填补本轮缺项。
- 回归运行不使用本地模型密钥，不启动开发库，不修改 `backend/data`。

机器可读定义：[agent-v1.json](./agent-v1.json)。场景的 `criterion` 是人工维护的验收标准；`testClass` 与 `testMethod` 精确指定代码判定器。一个场景可能包含多个角色或异常分支，不把循环内的断言另计为场景。

## 运行

在项目根目录的 PowerShell 中运行 `./scripts/Evaluate-Agent.ps1`。默认只运行这 40 项场景，报告输出到 `output/agent-evals/` 下独立的本次目录。整体不通过时返回非零退出码；无需先启动前后端。

完整项目回归仍用 `./scripts/Verify.ps1`。固定场景的选择不是完整测试集的替代，角色变更、协议与其他业务检查仍由全量回归覆盖。

## 真实模型评测边界

本版提供可重复的业务回归基线。真实模型准确率需要另建合成问法集，固定模型版本和预期工具／字段，逐条实际调用并记录用量、耗时和失败样例；不可用本版替身通过率替代。复杂语义及权限结论还需结合人工审查。新增业务或修复失败时，应更新独立验收标准和版本，避免只改评分器让失败消失。
