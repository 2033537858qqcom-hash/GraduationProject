## 校内平面图补充（当前独立沙盘）

用户随后提供了“西校区平面示意图”照片，现保存在 [平面图原文件](../../../frontend/public/campus/west-campus-layout-reference.jpg)。[文件信息与核对记录](plan-reference-2026-10-19.json)保留来源、尺寸和 SHA-256；照片没有标注编制日期、比例尺或楼层。

独立沙盘根据这张图补全 **39 个地点、26 个楼体图示块体**，包括图书馆、诚毅楼、科技信息楼、工程中心、汽车实训室、城轨实训室、明德楼、实验楼、两处餐厅与学生公寓区。华信路、文明大道、成才大道、桃园路作为可检索地点和道路中心线呈现。其余图示道路不虚构名称。

- 明德楼教室、宿舍和医务室按同一楼体关联展示；澡堂使用钢构餐厅东端的关联位置标记，未另建重叠楼体。
- 4号楼与4号公寓分别展示；8号楼没有独立框线，仅建立位置标记。
- 图中原名“实验楼”“工程中心”“3号楼”与高德的“一号楼/叁号实验楼/工程训练与创新中心”等记录不强行合并。
- 独立沙盘使用示意图相对位置，**不等比例、不附加未测得的经纬度、不用于实地导航**。3D高度为显示值，块体边界不代表实际建筑外轮廓。
- 高德模式继续使用14条API记录及卫星影像描绘的建筑叠加。`campusSceneData` 显式区分 `reference` 与 `geographic` 两种表示，平面图块体不会叠加到高德实景地图上。

图书馆、诚毅楼、科技信息楼已进入平面图沙盘。其他学校资料中的“一号实验楼”与“明德南楼”未在本图中同名独立标出，目前仅保留为名称待核对项。

数据源：`frontend/src/campus/westCampusPlan.ts`；地图记录：`frontend/src/campus/westCampusMapData.ts`。

## 留存证据

- [公开 POI 原始返回记录](amap-pois-2026-10-19.json)：合并“郑州工业应用技术学院”“楼”“郑工”的校区周边查询，保留 ID、名称、地址、类型和 GCJ-02 坐标。原始结果含旧名称和周边学校，不能直接全部作为校园楼宇导入。
- [主体区域卫星影像](satellite-overview-2026-10-19.png)、[较大范围卫星影像](satellite-extent-2026-10-19.png)：使用项目校准界面截取。楼体与道路依据画布内影像描绘，截图旁的旧版地点目录不属于地理证据。
- 坐标标定：`frontend/src/campus/westCampusLayout.ts` 中记录画布范围与三个可见坐标读数。北向对应模型 -Z；模型单位与真实高度无关。

## 首轮高德资料补充（地图模式）

14 个有独立高德记录的地点：东院1号楼、2号楼、叁号实验楼、工程训练与创新中心、明德楼、大学生创业孵化园、孵化园1号楼、机电工程学院地图标注、郑工餐厅、4号公寓楼、5号宿舍楼、7号宿舍楼、停车场、快递服务点。

沙盘增加 32 处影像屋顶轮廓、7 段可见道路中心线、庭院与北侧运动场环境。地点使用独立蓝色位置标记，浅色楼体不直接绑定尚未核实的楼名。地点标记位置是 API 收录点，不等于入口；屋顶描绘不是地籍测绘，模型高度统一为展示高度。

两个1号楼的 ID 与位置不同，分别展示。郑工餐厅与叁号实验楼相邻，两个POI不能证明各有一栋独立建筑，因此未生成两个重叠楼块。旧版“弘毅广场”“学生综合事务驿站”“学生生活园区”等缺少定位证据的条目不再使用；旧版北偏的校区视野已更正。

## 高德资料的局限（与校内平面图分别记录）

- 科技信息楼、诚毅楼、西校区图书馆、一号实验楼：校方[2025年第4期审核评估简报](https://pjb.zzuit.edu.cn/zhengzhougongyeyingyongjishuxueyuanbenkejiaoyujiaoxueshenhepinggugongzuojianbao2025niandi4qi.pdf)提及。前三者已按用户平面图补入独立沙盘，但准确地图坐标及与卫星屋顶的对应仍未测定。
- 明德南楼：校方[校内服务资料](https://center.zzuit.edu.cn/xnfw.htm)提及，尚待定位。
- 明德楼另有“男生宿舍”地图记录，位置与“明德楼”记录不同，不直接合并；用途仍需最新校内资料确认。
- 高德北侧运动场及东侧相邻区域存在其他学校标注。地图模式保留其归属不确定性；独立沙盘依据用户平面图纳入运动场及东侧公寓区的图示位置，两种来源不互相替代，也不据此推断当前预约开放情况。
- 尚未核实各栋楼的真实立面、层高、楼层、入口与房间分布。

地址依据：[学校2026年招生章程](https://zsb.zzuit.edu.cn/info/1003/1554.htm)。明德楼名称另有[校方2025年第2期教学检查简报](https://pjb.zzuit.edu.cn/zhengzhougongyeyingyongjishuxueyuanbenkejiaoyujiaoxueshenhepinggugongzuojianbao2025niandi2qi.pdf)支持。
