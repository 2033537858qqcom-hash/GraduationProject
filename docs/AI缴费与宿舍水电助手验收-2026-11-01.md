# AI 缴费与宿舍水电助手（2026-11-01）

后续 V41 已补齐多事项查询、充值条件逐步补充和历史关联恢复，最新验证见[AI多事项查询与连续追问验收](./AI多事项查询与连续追问验收-2026-11-01.md)。本文保留 V40 的验证口径。

缴费大厅中的助手新增本人账单、收费依据与支付状态、宿舍水电单价及充值记录、充值报价查询；财务岗位新增对账待办查询。本地模式可直接使用，DeepSeek 模式按当前账号授权的工具进行规划。

## 可以这样测试

| 问法 | 行为 |
| --- | --- |
| 我还有多少钱没交？ | 返回本人待支付金额和最近账单，链接到原账单；汇总包含有财务处理申请的待缴账单。 |
| 这笔费用怎么计算的？ | 在本人账单详情页读取费用依据、创建时价格快照和数量。 |
| 我的未缴账单 → 第二笔为什么这么贵？ | 按本次对话上一轮展示顺序选择账单并重新校验本人权限；缺少关联时提示选择，不猜编号。 |
| 我们宿舍电费多少钱一度？ | 从当前入住宿舍绑定的电表读取有效单价和演示余额。 |
| 充20度电要多少钱？ | 调用现有宿舍充值报价接口计算；示例单价 0.61 元/度时应付 12.20 元。 |
| 刚才充值到账了吗？ | 展示本宿舍最近充值记录及演示到账／冲正状态；选择具体本人账单后可进一步查询其支付状态。 |
| 有哪些对账差异等我处理？ | 经办查看待核查与核查中事项，复核岗位查看可复核事项；链接到财务原页面。 |

## 数据与操作边界

- 五个新工具为 `my_payments`、`payment_detail`、`my_dorm_utilities`、`quote_dorm_recharge`、`finance_reconciliation_pending`。
- 查询仅展示当前账号本人或财务授权范围数据。账户、任意 URL、他人身份等额外参数会被拒绝；本人账单上下文在调用模型前校验。
- 报价不创建账单、不支付、不退款；账单详情不主动请求支付平台。已发起支付且系统尚未确认时显示“支付结果待核验”，不把下单当作已付款。
- 宿舍余额仍是演示到账用量，未接设备、未扣减实际消耗；室友分摊在系统外处理。
- 模型只接收本次经确认的问题、工具定义及页面业务类型。账单事实、对话历史、实际编号和排序引用留在本地；缺少报价条件时提示补充。
- V40 为历史对话新增可空的账单序号引用字段，保存至多 8 个本地账单编号；为财务双岗增加助手只读查询权限，不授予新的财务操作权限。旧对话和账单保留。

## 启用

在 IDEA 重新运行 `CampusApplication`，启动时自动应用 V40，然后刷新前端。学生在缴费大厅打开助手，财务人员在财务收费页打开助手；如财务账号的旧登录状态尚未更新，请重新登录。
