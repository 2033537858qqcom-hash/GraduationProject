# Agent 在校证明任务执行（2026-11-02）

V45 在预约、报修和请假任务基础上增加在校证明草稿任务，复用现有登记资料核对、草稿保存和学院审核流程。

## 使用方法

1. 在 IDEA 重新运行 `CampusApplication`，应用 V45 后刷新前端。
2. 学生进入助手的 **Agent任务**，输入“帮我准备在校证明草稿”；也可明确选择“在校证明草稿”。混合目标需选择一种任务或分别办理。
3. 在本地表单填写实际证明用途。未填写时 Agent 会追问，不根据登记资料推测用途。
4. Agent 核对有效指南，读取本人当前登记资料和学院办理资格。预览逐项展示姓名、学号、学院、专业、班级、校区、实际用途及指南版本。
5. 本人核对后勾选确认，保存草稿；Agent 再读取原证明申请，核验用途、登记快照和草稿状态。
6. 通过“打开原证明申请”检查并手动提交，由所属学院学生事务人员审核。任务完成表示草稿保存并核验，证明文件仍由原业务审核流程生成。

## 执行与权限

- 六步路径：`check_certificate_requirements → inspect_certificate_identity → prepare_certificate → save_certificate → verify_certificate → finish`。缺项追问或修订会增加执行步骤。
- 创建、列表、恢复和每步执行复用本人会话与 `certificate:apply` 权限。其他账号不能读取该任务；其他岗位不能凭借预约或报修权限办理本人学生证明。
- `AgentCertificateMissionTools` 复用 `AgentCertificateDrafts.preview`、`CertificateService.eligibility`、`save` 和 `detail`。
- 确认摘要绑定实际用途、完整登记快照、指南版本、当前办理资格、本人及安全版本。用途修改使前端确认失效；登记资料、资格或指南变化会要求重新核对确认。
- 保存事务再次核对当前登记资料，并把预览中的 `expectedIdentity` 交给原服务校验。登记资料不完整或指南撤下时不能保存；没有学院处理人员时沿用原业务规则，允许保存草稿并提示暂不能提交。
- 核验原申请的本人归属、业务请求键、用途、完整登记快照、登记确认、数字交付方式、版本和 `DRAFT` 状态。保存后原页面已编辑或提交时保留原申请，任务提示进入原页面核对。
- 本地用途与登记资料不进入模型观察；模型只接收已授权目标、当前允许动作和工具状态／数量／缺失字段。用户自行写在目标中的内容属于其确认发送的目标。
- 共用任务租约、幂等重试、取消、中断恢复和24步预算。证明任务不能执行其他业务域动作；原“准备证明”辅助入口继续保留。
