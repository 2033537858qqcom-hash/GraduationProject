# Agent 持久会话与任务恢复验收

日期：2026-10-11，Asia/Shanghai。接续[证明辅助阶段](./Agent证明预览与登记确认验收-2026-10-09.md)，新增 V12 迁移。

## 实际交付

登录后右下角 AI 对话新增“历史对话”和“新对话”。会话按本人保存在数据库中，重新登录或刷新后默认打开最近更新的对话；历史列表可切换其他对话。会话标题来自第一条问题或准备事项，每页 10 条，可翻页。

历史查询保留用户的问题、方式、原上下文、执行状态和时间，不保留个人查询结果或模型回答。恢复后明确显示“结果需重新查询”；点击“重新查询”只填入问题，用户手动发送后才重新鉴权并获取最新结果。使用 DeepSeek 时，每次发送仍须同意，历史不会自动外发或重放。失败或后端重启时未完成的问题保持可见，需用户主动重查。

“准备请假”和“准备证明”改为服务端任务。“核对并暂存”保存规范化字段，读取当前指南及本人资料后生成预览；已核对字段在刷新、重新登录后可恢复。尚未核对的编辑保留离开提醒，取消离开继续编辑，放弃修改后可恢复最近一次暂存。表单确认和模型发送同意均不会持久化，恢复后必须重新勾选。联系方式、登记资料及表单不自动传给模型，主动写入本次模型问题的内容仍会随该问题发送。

每个对话可包含多项任务。“历史对话”中的“当前对话的准备任务”提供具体任务入口，可找回早先的预览或关联申请。最新任务作为准备入口的默认选择，同类旧任务仍可单独恢复。

保存普通业务草稿与关联任务处于同一事务。服务器使用固定业务请求键，重复确认、请求响应丢失后重试或重启后恢复，都返回原申请。关联后恢复直接读取原请假／证明申请的当前状态、版本和入口，不展示旧预览，不再建档。提交、材料及岗位处理继续由原页面人工完成。

## 接口与数据

| 对象／接口 | 行为 |
| --- | --- |
| `agent_session` | 本人会话、创建请求键、标题及更新时间；本人列表最大每页 20 条 |
| `agent_turn` | 提问、查询方式、上下文、状态及执行标识；详情返回最近 20 条，可按游标查更早提问 |
| `agent_task` | 准备类型、规范化字段、任务版本、服务器业务请求键及关联编号；每个对话最多 50 项 |
| `GET/POST /api/assistant/sessions` | 本人分页列表／幂等新建；写操作校验 CSRF |
| `GET /api/assistant/sessions/{id}` | 本人历史及当前有权限的任务摘要，不返回旧业务事实 |
| `POST /api/assistant/sessions/{id}/query` | 请求键去重；重复请求返回记录，不重放查询／模型调用 |
| `POST /api/assistant/sessions/{id}/tasks` | 幂等创建准备任务；不建普通申请 |
| `GET /api/assistant/sessions/{id}/tasks/{task}` | 重查本人权限、当前指南与登记资料，或关联申请的真实状态 |
| `POST …/tasks/{task}/leave`、`…/certificate` | 按任务版本核对并暂存，旧窗口不得覆盖新版本 |
| `POST …/tasks/{task}/save` | 用户亲自确认后事务保存并关联；证明还校验所核对的本人登记快照 |

所有接口要求 `agent:query`，准备任务还要求对应业务申请权限。其他学生和管理员不能读取他人会话。身份或归属变化沿用实时会话失效；重新登录后不再展示无权限的任务摘要。查询和模型准备沿用单账号进行中限制；模型调用不持有数据库写锁，返回后重新校验权限和任务版本。

恢复不自动调用模型、不恢复旧确认、不自动提交申请。规范化字段存入本地服务数据库，数据库备份应按私有数据保护。旧的独立准备接口继续保留兼容，当前界面改用会话任务接口；V11 以前仅在内存中的对话不能追溯恢复。
