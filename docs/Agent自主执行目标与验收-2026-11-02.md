# 校园 Agent 自主执行目标与验收

用户目标：完成直到成为真正的 Agent。基线为 V45（`2497407`），已有四类本人草稿和可靠执行底座。目标持续有效；下列条件全部有当前证据前不标记完成。

## 完成条件

- [x] 目标级动态规划：根据自然语言建立有依赖关系的多业务计划，支持预约、报修、请假、在校证明；不以关键词单选代替模型规划。
- [x] 自主工具选择与参数：模型在多个有实际意义的工具中选择，参数经过类型、范围和实时权限校验；能读取有效规则、检查条件、比较候选和准备业务任务。
- [x] 反馈与重规划：工具失败、冲突、无候选和中途目标变更能进入下一轮决策；能重新查询并提出替代方案，不虚构成功。
- [x] 确认办理闭环：核对真实草稿后，由本人按精确快照授权正式提交；授权随字段、业务版本、资格或权限变化失效；提交后读取原业务核验。
- [x] 持续跟踪：持久跟踪已提交的本人事项，恢复时重新鉴权，仅在有意义的状态变化或需要本人操作时发送站内提醒。
- [ ] 产品入口：目标、可修改的计划、执行记录、缺项问题、原申请入口、分别确认保存／提交、取消及刷新恢复可在真实页面使用。
- [x] 工程保护：租约、版本、幂等、取消、预算、跨账号与跨域权限、会话删除和数据迁移保护覆盖新增目标级执行层。
- [x] 真实评测：保留未参与提示调试的目标、动态改序、混合业务、冲突改方案、工具失败、用户修订、拒绝越权、确认失效与恢复场景；记录实际工具序列、业务结果、耗时和模型用量。单个固定六步成功不作为自主规划证明。
- [ ] 验证与交付：新增核心代码达到至少80%行覆盖率，相关回归、全量回归、前端lint／类型检查／构建、H2及隔离MySQL迁移、浏览器关键流程通过；交付明确支持边界和证据。

## 实现约束

目标级执行器负责计划、读取结果、选择下一工具与重规划；既有业务服务继续实施权限及业务规则，既有草稿任务可以作为执行工具。只有本人真实确认可以授权写入或提交，模型不能生成授权。

目标、用户明确同意发送的补充文字、有效公开指南与场地候选、脱敏工具结果可参与规划；本地联系方式、登记身份、业务正文及私人日程明细不自动发送。只存结构化计划、动作和执行结果，不存模型隐藏推理。

本目标不要求代替学校审批人员作决定。正式审批、付款和他人业务仍遵守原岗位边界。支持范围为本项目已有业务接口，成功必须由原业务状态证明。
