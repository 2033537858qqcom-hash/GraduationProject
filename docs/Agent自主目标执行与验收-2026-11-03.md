# Agent 自主目标执行与验收（2026-11-03）

本阶段在V45单项草稿任务上增加目标级Agent。模型组织多事项计划、选择带参数的工具、读取反馈并调整方案；原业务服务继续校验身份、范围、资格和状态。新增V46目标记录及V47预约指南。

**当前处于最终验收，尚未宣布整个目标完成。** 浏览器工具返回 Local browser use is disabled in Work settings，完整浏览器流程没有本阶段证据；没有通过其他控制方式绕过设置。

## 使用方式

1. 重新运行后端应用V46–V47，刷新页面并确保DeepSeek已连接。scripts/Start-Backend.ps1可以读取当前Windows用户已保存的加密凭据。
2. 助手选择“自主Agent”，描述目标，可以组合证明、请假、报修和预约，并说明先后关系。“Agent任务”保留原本的本地单项草稿流程。
3. 同意发送本次目标后，查看模型建立的计划及实际工具记录。模型可以先读指南，也可以先计划，顺序由目标与真实结果决定。
4. 用户已明确写出的实际用途、事由和时间等由模型提取到本地预览。日期不明确时追问；联系方式、登记身份和报修地点在本地表单核对。
5. 每个事项保存草稿需要本人核对确认；要求正式提交时，再展示原申请当前内容，由本人另行确认提交。
6. 可以补充或调整目标，也可停止单个事项的后续办理。已保存或提交的原申请保留，停止目标不会自动撤回申请。
7. 要求跟踪时，提交并核验后持续读取原业务，每分钟检查一次。无变化不提醒，变化或需要本人操作时发送站内提醒，结束以原申请实际状态为准。

## 自主执行能力与边界

| 能力 | 实现及证据 |
| --- | --- |
| 动态计划 | set_plan组织至多6个有依赖的事项，拒绝循环、未知依赖和越权业务；历史保留，停止事项由本人决定 |
| 工具与参数 | 模型选择指南、字段、预览、场地、替代查询、提交、核验、结果关联及跟踪；后端按当前状态提供适用工具和任务键 |
| 反馈与重规划 | 区分缺条件、无候选、冲突、变化和错误；连续无变化读取会请求有效补充，重复调用不冒充新进展 |
| 替代方案 | 实际上午占用后，按用户允许的下午时段改查，并比较真实候选容量 |
| 确认办理 | 保存和提交分别确认，模型不能制造授权；取消目标后旧授权不再使用 |
| 原业务核验 | 四类事项均调用原保存、提交和详情服务；实际业务状态决定成功 |
| 复合跟踪 | 同一事项可使用TRACK目标；独立跟踪步骤通过link_task_result关联前置的同一份已核验申请，不重复建档 |
| 持久恢复 | 目标、计划、工具记录、子任务、授权及跟踪状态入库；失去关联的准备任务按固定请求键恢复 |
| 执行保护 | 每目标80步、每请求8步及60秒预算；租约、版本、幂等、取消和恢复；模型调用不持有数据库事务 |

提交授权绑定原申请内容及版本、本人安全版本、当前资格、指南版本和办理目标。执行提交时在原业务写锁下再次核对，变化需重新确认。摘要按Map键排序生成，避免JVM重启后的遍历顺序造成同一内容摘要不同。

模型接收经同意发送的目标与补充文字、场地查询条件、公开指南与候选、字段是否已提供及脱敏状态。本地联系方式、登记姓名／学号／班级、私人日程明细及表单正文不会自动加入模型上下文；用户自行写进目标的内容属于其同意发送的文字。

模型不代替学院、辅导员、后勤或场地负责人审批，不支付，不操作他人申请。当前不含调宿目标执行，原调宿辅助入口保留。平台业务数据仍为演示记录。
