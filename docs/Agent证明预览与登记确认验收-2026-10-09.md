# Agent 在校证明预览与登记确认验收

日期：2026-10-09，Asia/Shanghai。接续[请假辅助阶段](./Agent请假预览与人工确认验收-2026-10-09.md)，继续使用 V11，无新增迁移。

## 实际交付

学生打开右下角 AI 对话，选择“准备证明”。可直接填写用途，或选 DeepSeek、逐次确认发送本次文字，让模型提取用途。缺少用途时补问，不自动生成用途。模型仅提取用途，姓名、学号、学院、专业、班级和校区由本地服务读取。

真实浏览器联调中，“实习单位要求我提供在校证明，用来核验在校身份。”提取为“实习单位核验在校身份”。用户可编辑用途；修改后必须重新核对并勾选本人登记资料及用途确认，才能保存草稿。这是一个已验证的普通演示问法，不代表已测模型正确率。

保存前再次读取当前指南、实时权限和登记资料。若登记资料变化，展示更新后的资料并要求重新确认；普通保存接口同时在写事务中比较用户已核对的 `expectedIdentity`，防止前端复核之后、保存之前的资料变化。普通证明表单也携带所展示的登记快照。此快照仅用于一致性校验，申请身份始终来自登录账号和当前数据库，不能借此指定其他学生。

确认后通过既有接口保存本人 DRAFT / V0，显示申请编号及原详情链接。原页面继续承担人工提交、学院事务人员审核、退回补交、撤回和受控演示 PDF 下载。既有查询可查询当前申请状态；没有模型提交、审批或直接下载他人文件的工具。

## 接口与交互约束

| 项目 | 当前行为 |
| --- | --- |
| 准备接口 | `POST /api/assistant/certificate/prepare`；CSRF、`agent:query`、`certificate:apply`；不写申请 |
| 用途 | 最多 300 字，缺失时补问；本地表单和模型整理结果都可编辑 |
| 模型字段 | 只接受一次 `collect_certificate_fields`、可选字符串 `purpose`；拒绝身份、确认布尔值、领取方式、状态、其他字段或工具 |
| 领取方式 | 沿用已有电子 PDF 下载，不新增线下领取或虚构材料要求 |
| 登记确认 | 由用户核对本地读取的六类资料及用途，模型不能代为确认 |
| 保存 | 复用 `POST /api/certificates/mine`；同一请求键重试复用草稿；结果不确定时保留请求键和资料 |
| 权限变化 | 模型返回后重新核对身份，旧会话或岗位失效停止交付 |
| 指南和资料 | 指南撤下或登记资料不完整时阻止助手保存；无有效学院处理人员时可存草稿，暂不能提交 |
| 预览生命周期 | 当前页面内存；收起或切换助手入口保留，取消离开保留，确认放弃清空，刷新或退出清空 |

DeepSeek 只自动收到本次文字及用途提取契约。登记资料、当前表单、历史补充和业务结果留在本地；用户主动写入本次文字的内容会发送，页面逐次确认。审计记录工具名、结果、耗时及令牌计数，不记录用途、登记资料或原文字。准备操作和既有查询、请假准备共享单账号进行中限制及每分钟三十次单实例限流。

请假与证明预览共用一份紧凑表单样式。未保存提示移到页面顶层，切换到查询入口或收起窗口后仍能正确显示。修复路由标题更新时机，只有导航成功才更新标题，取消导航保持当前页面标题。
