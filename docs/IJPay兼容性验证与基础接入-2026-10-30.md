# IJPay 兼容性验证与基础接入

日期：2026-10-30。

后续进展：演示账单和支付宝沙箱支付入口已开发，最新状态见[支付宝沙箱演示缴费接入](./支付宝沙箱演示缴费接入-2026-10-30.md)。以下保留兼容性验证当时的记录。

当前采用 `IJPay-AliPay:2.9.13`，已在后端 POM 引入。适配后可在当前 Java 21、Spring Boot 4.0.8 和 Jakarta Servlet 环境中使用已验证的核心接口。收费账单、支付 API 和前端收银页面尚未实现，本次没有调用支付宝沙箱或正式平台。

## 实际兼容性问题与解决方式

1. 发布包 `AliPayApi` 的网页支付便捷方法仍引用 `javax.servlet.http.HttpServletResponse`。在当前项目仅有 Jakarta Servlet 的类路径中，调用其 `tradePage(client, model, notifyUrl, returnUrl)` 字符串重载也出现编译错误：找不到旧 `HttpServletResponse`。
2. 改为 `AliPayApi.pageExecute(client, request)` 可通过编译，但没有旧 Servlet 类型时，运行仍报 `NoClassDefFoundError: javax/servlet/ServletOutputStream`。
3. 在后端引入 `javax.servlet:javax.servlet-api:4.0.1`，作用域设为 `runtime`，为 IJPay 提供类加载需要的类型。当前 Web 控制器、Spring MVC 和 Tomcat 继续使用 Jakarta；不要把当前请求或响应对象传给 IJPay 的旧 Servlet 方法。

当前仅引入支付宝模块；IJPay 的微信模块、证书模式和其他渠道尚未验证。模块源码和发布包参考 [IJPay 仓库](https://github.com/Javen205/IJPay)、[支付宝模块 2.9.13 POM](https://repo.maven.apache.org/maven2/com/github/javen205/IJPay-AliPay/2.9.13/IJPay-AliPay-2.9.13.pom)。

## 工程使用约定

- 使用显式 `AlipayClient` 参数调用 IJPay 核心接口，避免依赖全局或线程缓存选择应用。
- 网页支付构造 `AlipayTradePagePayRequest` 后调用 `AliPayApi.pageExecute(client, request)`，由本项目的 Jakarta Web 层处理结果。
- 支付宝通知使用 IJPay 所引入的支付宝 SDK 验签；验签通过后，业务层仍须校验账单归属、应用、收款商户、订单、金额和状态。
- `javax.servlet-api` 只作为运行时类型依赖，不增加旧 Web 容器、不更换 Spring Boot 版本，也不在业务源代码中使用旧 Servlet 类型。
- 当前没有支付服务 Bean、公开支付端点或支付凭据配置，加入依赖不会自动发起收款。

## 验证

先在 `artifacts/ijpay-compatibility-2026-10-30/` 使用与当前后端相同的依赖做隔离验证，保留三个阶段：

- `legacy-overload.log`：复现 `tradePage` 重载的编译失败。
- `adapted.log`：复现仅换用核心接口但未补运行时类型的类加载失败。
- `runtime-compatibility.log`：补运行时依赖后 4 项通过，包含实际启动嵌入式 Tomcat 的 HTTP 请求，确认请求仍为 Jakarta 类型。

正式工程新增两组可重复检查：

- [IJPayCompatibilityTest](../backend/src/test/java/cn/zzuit/campus/payment/IJPayCompatibilityTest.java)：6 项。网页支付签名表单、并发显式客户端隔离、通知金额篡改与错误公钥、非法签名、本机模拟网关查单及返回金额篡改。模拟网关使用每次进程内生成的密钥验证 HTTP、JSON 解析和签名相关依赖，密钥不保存、不打印。
- [IJPayIntegrationTest](../backend/src/test/java/cn/zzuit/campus/payment/IJPayIntegrationTest.java)：3 项。在隔离 H2 中启动完整校园应用，核对健康检查、匿名访问限制、CSRF 获取及 Spring Dispatcher 的 Jakarta 类型。

执行方式，在 `backend` 使用 JDK 21：

```powershell
mvn -B '-Dtest=IJPayCompatibilityTest,IJPayIntegrationTest' test
mvn -B test
```
