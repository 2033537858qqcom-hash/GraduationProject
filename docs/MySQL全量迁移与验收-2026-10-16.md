# MySQL 全量迁移与验收记录

日期：2026-10-16，Asia/Shanghai。工程版本 0.1.0，数据库版本 V24。

## 1. 验证目标

在非 H2 的真实关系型数据库引擎（MySQL 8.0+）环境下，验证系统自 V1 基础身份至 V24 统一办理时间线索引的全部 24 个 Flyway 数据库迁移脚本的语法兼容性、外键约束、CHECK 约束处理以及初始化数据播种（Demo Seed）。

| 项 | 配置值 |
| --- | --- |

| 验收独立数据库 | `campus_acceptance`（字符集 `utf8mb4`，排序规则 `utf8mb4_unicode_ci`） |

| 连接参数 | `useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai` |

| 临时测试端口 | `18082`（避免与日常 8080/18080 端口冲突） |
