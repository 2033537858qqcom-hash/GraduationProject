# 三维校园分布修复验收

日期：2026-10-17。范围：前端 `/campus/explore` 的建筑身份、分布、选择与证据说明。未更改业务数据库或已有预约记录。

## 依据及采用方式

用户提供 `D:/QQfile/mmexport1792205648476.jpg` 并明确说明为真实学校建筑分布图。本轮原样复制到 `frontend/public/campus/east-campus-layout-reference.jpg`，SHA-256 为 `88B5A50EEEBCA01D5E221B431AC7FE082E8763332470FE3A998D0ACAD161D0B4`，与附件完全一致。图中未标明编制日期。

- 楼名、功能分布和相对方位优先采用这张分布图。
- 建筑外轮廓继续采用项目保存的高德卫星描摹数据，并参考上一轮已留存的腾讯、Google 卫星画面；未把手绘图像直接当作具有米制比例的测绘数据。
- 分布图能确认名字、但尚不能逐栋对应影像屋顶的位置，仅用位置点表示；不编造楼体或实测入口。
- 建筑高度仍为模型展示值，不据此推断楼层、实际高度、室内设施与预约容量。

## 验证

使用 AI Regression Testing 技能，针对已发现的问题补充回归检查。最初7项回归均能在修复前失败；收到分布图后，按新证据更新了红体馆、静逸/餐厅分区、风华楼及服务中心的位置契约，没有继续将已有新依据的建筑判作“应删除”。

- 前端测试：84项通过，含7项校园回归测试。
- `pnpm check:campus`：通过；31个地点、47个特征、38个主网格、7204个三角面。地点数包括入口和位置点，不等于建筑栋数。
- `pnpm build`、`pnpm lint`：通过。构建保留Three.js页面已有的大体积包提示。
- 回归覆盖：锦绣楼身份、锦绣餐厅/静逸楼POI所在分区、原轮廓面积与双内院保留、删除无依据的室内库存、已命名建筑与体育场/水体的交叠、分布图方位关系、标记点类型、元数据高度与渲染、射线点选。
- 浏览器检查：目录搜索“锦绣”、餐厅独立定位与高亮、关联切换静逸楼、俯视布局、分布图入口；原图资源正确加载为724×640。桌面俯视14个可见标签未发生矩形交叠；375px视口下无横向溢出、只有一个canvas、关联按钮可见。截图保存在 `artifacts/campus-map-review-2026-10-17/`。

几何检查对信科楼与建工楼旧描边连接处仍明确保留小于10 px²的容差（两处约9.255、9.229 px²），并未将其描述为实测无误差。匿名西北屋顶属于未分栋上下文，旧描边局部相交不被当作两个独立命名建筑的校验通过证明。
