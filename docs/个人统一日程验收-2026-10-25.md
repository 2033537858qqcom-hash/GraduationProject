# 学生个人统一日程验收

日期：2026-10-25（Asia/Shanghai）。工程版本：0.1.0；数据库沿用 V33，本批无新增迁移。

## 本批完成

学生门户新增“我的日程”，导航、门户主要入口、服务目录与学习页面均可进入 `/portal/schedule`。采用周日期条和按日清单，沿用现有学校配色，不替换原课表、请假或预约页面。

- 汇总本人有效教学关系下的课程、已发布考试、已批准／待销假／已销假请假，以及待审／已批准／使用中／已核销预约。
- 请假使用已生成的请假日程，确认销假后的缩短时段与原请假日程一致；不把原批准快照误当成持续离校时间。
- 草稿、退回、驳回、撤回、取消及过期预约不作为日程安排显示。待审预约明确标记“待审批”，不宣称已经批准。
- 个人时间重叠作提示，包含待审预约时特别标明；相邻时段不算重叠。不会修改审批结果或因个人重叠擅自拒绝其他业务。
- 日期区间按北京时间解释，后端结束日期不包含在区间内。前端按周一定位，支持跨月／跨年、闰日、跨日安排与午夜结束的分日显示；同一跨日事件仍只计作一项安排。
- 支持上一周、下一周、本周、日期选择、类型和日期组合筛选。周、类型和日期保存在 URL，浏览器返回保留筛选。
- 每项安排链接原业务：课程定位来源学期和周，考试定位来源学期，请假／预约打开本人对应申请详情。链接按来源校验，拒绝外部或跨业务注入。
- 窄屏保持同一套数据和操作，时间、业务类别、状态、地点和重叠提示分层展示。

## 接口和授权

`GET /api/schedule/mine?from=2026-10-26&to=2026-11-02`。

- 要求实时 `portal:read` 权限，分别按当前 `learning:read`、`leave:apply`、`reservation:apply` 决定可读取来源。没有来源权限时显式列出未汇总的类别，不沿用旧会话里的权限列表。
- 仅查询当前用户，额外传入 `userId` 不改变范围；教师或管理员没有学生门户权限时返回 403，匿名返回 401。
- 查询范围为 1—42 天，单次最多 500 项；过密时要求缩短区间，不静默截断。缺参数或日期错误返回 400；本批同时修正通用缺参数异常此前被返回为 500 的问题。
- 四来源在只读快照事务中读取，不另外保存日程副本。某来源读取失败时整次请求失败，页面显示错误和重试，不输出部分来源后宣称“暂无日程”。
- 响应 `Cache-Control: no-store`。聚合结果不携带联系方式、请假事由、附件、学生名单或密码信息。

## 使用及边界

更新代码后重启后端、刷新前端，从“学生首页 → 我的日程”进入。没有新增迁移或修改日常数据库、环境凭据与真实模型配置。验收临时服务、页面和窄屏包装文件均关闭或移除；原有住宿初始化及开题报告相关用户改动保留，未加入本批提交。

本批实现学生日程，尚不包含教师／工作人员的统一个人日程、手工创建事项、ICS 订阅导出、日程提醒偏好或 Agent 日程查询工具。使用中预约仍按计划时段展示，真实超时占用与结束核销继续由原预约模块处理。展示依赖当前业务记录，不等于接入学校正式教务系统；最新 MySQL 迁移与备份恢复验收仍待推进。
