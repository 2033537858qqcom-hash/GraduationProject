# 交易对账差异跟踪验收（2026-11-01）

财务人员在“财务收费 → 交易明细核对”粘贴或选择按模板整理的交易明细，生成差异后，财务经办可将异常保存为跟踪事项。保存时服务端再次按当前账单核对，只保存异常行及必要的当时快照，不保存原始 CSV；异常字段过长时会截短。

## 处理流程

1. 经办人开始核查并填写说明；需要换人处理时，其他经办人可接手，操作记录保留。
2. 核查完成后，经办人提交独立复核。复核人可填写说明后关闭事项，或退回经办人继续核查；经办人不能复核自己处理的事项。
3. 关闭后仍可查看记录，经办人可按需重新开启。列表支持按状态筛选和分页；工作台待办可直达指定事项。
4. 岗位调整时，系统将未完成的对账工作纳入交接保护；紧急撤权造成岗位缺口时，管理员可在职责异常中看到相应事项。

对账事项仅记录核查过程和结论，不会将账单标记为已付款、改变账单金额或修改退款状态。需要确认实际到账时，仍须在原账单通过支付平台查单。事项展示的本地金额与状态是保存时的快照，不会随着账单后续状态变动而更新。

## 权限与数据

- 保存、开始、接手、提交和重新开启由财务经办执行；退回及关闭由财务复核执行。财务岗位可查看事项与记录，其他岗位无权访问。
- 每次操作要求填写说明，记录操作人及时间；版本控制防止过期操作覆盖新状态，相同请求重试不会重复创建事项。
- V39 新增批次及事项表，不更改历史账单和既有收费标准。对账输入上限沿用原有核对功能：每批 256 KB、2000 笔。
