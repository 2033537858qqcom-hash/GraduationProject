# 公共场地与设备借用预约与三维校园校准验收 (2026-10-16)

更新日期：2026-10-16。

## 1. 概述与背景

依据用户指导，本项目完成“选项 1：公共场地/设备借用预约”的研发，并在开发前对照腾讯地图、谷歌地图及学校真实校貌（郑州工业应用技术学院东校区），对现有 Three.js 三维校园导览与数字沙盘进行了全景校准与精细化重构，建立了“三维数字沙盘探索 -> 可借用资源联动 -> 在线防冲突预约申请 -> 学生事务多级审批 -> 电子通行凭证签发 -> 统一办事时间线追溯”的全闭环业务体系。

## 2. 交付清单与核心成果

### 2.1 三维校园沙盘校准与场景升级 (Three.js)
- **多源真实地图校准**：依据腾讯地图高德影像与实地规划，新增并精确校准了 **23 处重要建筑与景观地标**，包含：
  - `east-gym`：室内综合体育馆（红体馆，主副赛场/羽毛球馆）
  - `east-dorms`：北区学生公寓组团（1-10号公寓楼群）
  - `east-affairs`：学生事务综合服务中心（一站式大厅/活动中心）
  - `east-admin`：行政管理中心（校级行政楼）
  - `east-golf`：秋月塘水上高尔夫练习场
  - `east-water`：秋月塘景观水系
  - `east-jinxiu`：锦绣食府（第一学生餐厅）
- **材质分级与高度体量映射**：
  - 图书馆白色石材与玻璃天顶 (`#eee7da`)
  - 体育场馆轻钢银蓝材质 (`#cad6de`)
  - 公寓暖灰砂石材质 (`#ddd5cb`)
  - 秋月塘水系高反射镜面材质 (`#438ca3`, 金属度 0.22, 粗糙度 0.16)
- **沙盘与借用业务无缝联动**：
  - 在三维建筑属性卡片中增加“可预约开放场地 / 设施”列表展示。
  - 支持一键点击“申请借用该处场地”，直通 `/portal/reservations?venue=${currentPlace.id}`。
  - 通过沙盘静态几何拓扑校验脚本：23 处地点、39 项特征要素、29 个主几何体、6,588 个面片，全部通过自动化检测。

### 2.2 场地与设备借用预约数据库 (Flyway V25)
- **`venue_resource`**：场地与设备目录表，预置 17 处真实校区资源（学术报告厅、智慧研讨室、室内篮球馆、室外网球场、便携扩音设备、4K录播云台等）。
- **`venue_reservation`**：借用预约单主表，支持草稿（DRAFT）、待审核（SUBMITTED）、待补充材料（RETURNED）、已同意（APPROVED）、已驳回（REJECTED）、已取消（CANCELLED）、已撤回（WITHDRAWN）7 大状态。
- **`venue_reservation_action`**：审计流转表，完整沉淀从申请、退回、修改、审批到取消的全生命周期历史节点与处理意见。
- **排期防重排与冲突检测索引**：建立 `(venue_id, status, ends_at, starts_at)` 复合索引，数据库层与业务层双重排他校验。
- **权限角色映射 (RBAC)**：
  - `reservation:apply`：学生（STUDENT）、教师（TEACHER）、辅导员（COUNSELOR）具备借用申请与本人撤回权限。
  - `reservation:review`：学生事务处（STUDENT_AFFAIRS）具备审批权（同意、退回补交、驳回）。
  - `reservation:manage`：系统管理员（ADMIN）具备资源配置与停用权。

### 2.3 业务服务层与冲突防范 (VenueReservationService)
- **实时时段防冲突算法 (`checkConflict`)**：支持毫秒级排查指定场地在预约时段是否存在重叠的有效预订（排除已取消或已驳回记录，排除当前编辑版本），返回冲突详情列表。
- **并发控制**：在保存与提交时采用乐观锁版本控制，结合行级锁预防并发预订超卖。
- **通知系统接入 (`NoticeService`)**：在提交、审核通过、退回、驳回时，自动向申请人精准派发个人系统通知，附带安全跳转链接。
- **统一办事时间线深度融合 (`AffairTimelineService`)**：
  - 将 `RESERVATION` 作为顶级办事业务纳入 `/api/affairs/mine` 统一汇聚列表。
  - 动态计算当前办理节点、下一步指引（如“凭电子通行凭证按时到达场地并联系管理员”）。

### 2.4 前端界面与全功能体验 (Vue 3 + TypeScript)
- **`frontend/src/reservations.ts`**：强类型 API 客户端与字典定义。
- **`ReservationPage.vue`**：
  - **场地与设备资源库**：卡片式浏览、分类筛选、按三维建筑联动过滤、容纳人数与规则展示、一键预约。
  - **排期占用日程弹窗**：按日期查看指定场地全天各时段占用情况（绿色空闲/黄色已占）。
  - **预约申请抽屉/表单**：支持快速时段填充（明天上午、明天下午、后天下午、周末上午）、实时冲突红绿灯检测、表单防走失确认（`useEditProtection`）。
  - **我的借用申请列表**：状态过滤、分页查询、详情查看、草稿编辑、申请撤回、事前取消。
  - **借用审批工作台**：供学生事务人员在线查看待办、核验冲突、签署同意/退回/驳回意见。
  - **电子入场与使用通行凭证 (Venue Access Pass)**：审批通过后自动签发带水印防伪编号的通行证，支持现场出示核验与一键浏览器打印。
  - **办事时间线内嵌**：详情下方直接嵌入 `<AffairTimeline>`，全流程节点可视化。
- **系统导航与工作台集成**：
  - 学生首页导航与服务中心加入“公共场地与设备借用”。
  - 统一办事中心（`MyAffairsPage.vue`）支持“场地与设备借用”筛选与时间线展开。
  - 岗位工作台（`WorkbenchPage.vue`）为学生事务人员集成“场地与设备借用审批”待办入口。
