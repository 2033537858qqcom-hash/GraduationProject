## 项目定位

项目名称：郑州工业应用技术学院校园综合服务平台。

以该校为背景完成本科毕业设计，建设原创学校展示网站、学生门户、教师与工作人员业务入口、管理后台及 Agent。现有业务范围与开发批次保持有效；学校名称的确定不代表已有校内系统对接或实际部署。

论文题目暂保留《基于 Java 与智能体的校园综合服务平台的设计与实现》，学校名称可写入研究背景与应用场景。题目最终按导师及开题格式确定。

## 公开资料与演示业务

- 学校名称、校训、学校介绍、校区及学院专业等公开资料采用可核验来源，并记录来源链接、资料日期与更新时间。动态办学统计在发布前另行核验。
- 学生、教师、账号、成绩、考试、住宿、预约、申请及维修记录使用明确标注的演示数据。演示账号不代表真实师生。
- 目前设计的预约期限、审批步骤、请假与证明流程属于项目业务规则，尚未核实为该校实际办事制度。
- 官网内容与 Agent 知识库共用发布版本和来源标识。Agent 回答学校事实引用学校公开资料，解释演示办理规则时说明规则来自项目配置。

## 品牌与素材

现有深蓝、白色、浅灰为用户已选定的项目设计方案，不标为该校官方标准色。学校名称、英文名称及校训用于正式工程中的统一品牌配置。

已采用[学校官网](https://www.zzuit.edu.cn/)实际使用的校徽、校名题字与英文名称组合标识，原文件来自 images/22/bslogo.png。官网、登录页与学生门户共用 SchoolIdentity，单色标识通过显示滤镜使用当前页面的深蓝或白色，保持原始形态；网页标签图标采用同一高清原图中的校徽区域。来源记录在 assets/brand/README.md。

当前官网与登录页摄影已改用[学校招生信息网](https://zsb.zzuit.edu.cn/)的校园全景、师生场景，以及[官网校园风光](https://www.zzuit.edu.cn/gyxy/xyfg.htm)的建筑与花枝照片；保留原图和页面来源。来源记录在 assets/campus/official/README.md，前端配置在 schoolMedia.ts。

原有湖畔、图书馆中庭与暮色庭院生成图和“澄川大学”HTML 原型保留为历史设计资料。Three.js 建筑资料仍待校准，现有 3D 场景继续明确为演示布局。

真实校名较长，正式前端需要为桌面与手机分别安排校名、标识和导航空间，避免将名称强行压缩到旧原型宽度。

## 对工程设计的影响

1. 学校身份集中配置，官网、学生门户、后台与 Agent 使用同一名称与资料来源。
2. 校区、院系组织、专业、行政班与教学班分别建模；资源、宿舍、课程地点和预约关联校区。组织支持上下级关系，具体机构目录按学校最新公开资料核验后导入。
3. 公开学校资料与演示业务记录分别标识来源，不将测试数据合并到学校实际规模统计。
4. 第一阶段继续推进工程结构、首批实体字段与接口契约，名称和素材调整与业务开发并行。

校园建筑及布局已按用户要求采用 Three.js，细化方案见[Three.js 校园探索设计](./Three.js校园探索设计-v0.1.md)。正式布局需要校准学校地图；技术验证可先使用有演示标识的场景。
