# 官网主视觉与轮播设计 v0.1

更新日期：2026-10-03。沿用已确认的校园叙事布局与深蓝品牌色。

学校背景已切换为郑州工业应用技术学院，详见[学校背景与品牌基线](./学校背景与品牌基线-v0.1.md)。以下生成图片继续作为布局和动效占位；正式工程采用核验的学校素材，不将这些图片标为该校实景。

## 视觉与交互

主视觉由湖畔校园、图书馆中庭和暮色教学楼庭院三张照片组成。照片使用同一虚构校园的材质、秋日环境和摄影语言，标题采用克制的衬线字体，文字与链接位置保持稳定。

每张图稳定停留约 7 秒；图片用 1.2 秒淡入转场，同时进行约 2.5% 的缓慢缩放。转场期间保留上一张不透明画面，待新画面完成后清理旧层，避免背景闪白。照片说明作 420 毫秒、3 像素以内的轻微渐入；标题不跟随照片飞入或移动。

底部提供场景说明、张数、直接选图、上一张和下一张。按最新设计要求去除播放与暂停按钮；手机保留直接选图，支持水平滑动，纵向手势继续用于滚动页面。

- 初始自动播放；鼠标悬停、键盘焦点进入、画面离开视口或页面进入后台时暂时停止计时。
- 手动选图、键盘左右键或水平滑动后重新计时；鼠标和焦点离开轮播后自动继续。
- 离开首页或切换设计方案后停止计时，返回可见页面后重新计时。
- 系统启用“减少动态效果”时默认暂停自动播放，手动切换直接呈现画面。
- 非当前照片不向辅助技术暴露；只在手动切换时播报场景与张数。

## 滚动显示

最新确认的校园叙事方案已改为首页、学校概况、院系专业等九个整屏章节。切换、栏目主题与导航以[官网整屏章节设计](./官网整屏章节设计-v0.1.md)为准。此前仅为新闻、公告添加渐入的设计已被此方案替代。

栏目详情页保留柔和的正文渐入。键盘聚焦会立即显示对应内容；系统启用“减少动态效果”或浏览器不支持观察器时直接显示。未启用脚本时正文也保持可见。
