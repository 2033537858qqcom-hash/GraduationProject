# 官网整屏章节设计 v0.1

更新日期：2026-10-03。用户已确认“整屏章节切换”：上下滚动依次进入首页、学校概况及后续栏目，每一屏呈现一个完整的主题。此设计替代此前仅为新闻、公告添加滚动渐入的解释。

## 信息结构与主题

当前校园叙事方案将学校官网的九个顶级栏目组织为章节。学校品牌、主导航、字体、图片摄影语言与内容入口保持连贯；章节以构图、明暗和内容重心区分。

| 顺序 | 顶级栏目 | 视觉与内容重心 |
| --- | --- | --- |
| 1 | 首页 | 大幅校园照片轮播、稳定的校训式主标题；新闻和公告保留直接入口 |
| 2 | 学校概况 | 明亮留白、湖畔校园图片；认识学校、历史与组织 |
| 3 | 院系专业 | 深蓝底色、学院目录；有秩序的学科与专业信息 |
| 4 | 教育教学 | 图书馆自然光、图片与正文左右对调；课程与实践 |
| 5 | 科学研究 | 暮色校园与深蓝叠色；研究方向、平台和学术交流 |
| 6 | 招生就业 | 明亮留白与灯火校园；报考、学习和发展 |
| 7 | 合作交流 | 浅灰底色、开放的文字布局；校企与学习交流 |
| 8 | 校园生活 | 沉浸式校园照片；社团、体育与艺术 |
| 9 | 信息公开 | 明亮的公开目录；机构、章程、通知和联系渠道 |

主题限于统一品牌中的深蓝、白色、浅灰与校园照片，不给每个栏目另配一套无关颜色。章标题使用同一衬线字体，导航和正文沿用清晰的无衬线字体。

## 切换与导航

- 展示区域内部上下滚动；桌面滚轮的一次连续手势推进或退回一章，惯性事件不会连续跳过多章。
- 相邻章节在 900 毫秒内平滑移动，起止速度均趋近于零；跨章节导航使用 1050 毫秒的移动。
- 章节正文以 750 毫秒透明度变化和 900 毫秒、22 像素以内的位移配合章节进入。章节背景与校园照片保持连续，不使用闪白或生硬的飞入。
- 顶部导航跟随当前章节高亮；点击导航定位到相应章节。底部提供章节序号与下一章入口，最后一章禁用下一章入口。
- 桌面栏目导航覆盖在章节顶部，使用 80% 不透明度的品牌深蓝与 12 像素背景模糊，校园图片可隐约透出。学校名称区域保持清晰的白底；白色栏目文字与当前栏目下划线保持可辨认。
- 窄屏导航维持原有展开布局，底色提高至 94% 不透明度。详情页导航保留正常文档布局；不支持背景模糊或启用减少透明效果时使用实色。
- 每章的具体链接仍打开独立栏目或详情页；详情中点击顶部栏目会进入对应章节，不增加“返回某某”入口。
- 窄屏改为上下排列。若章节正文超出显示区域，先允许阅读当前章节，再跨章，避免内容被截掉。
- 支持键盘 PageUp、PageDown；键盘焦点进入某章时同步章节状态。启用“减少动态效果”时直接定位，关闭章节位移与轮播自动播放。
- 保留三张校园照片轮播，继续使用 7 秒停留与 1.2 秒图片转场，不显示暂停按钮。

## 状态与验证

手动切换会保存所选章节。刷新可恢复章节；尺寸变化保持阅读位置。详情退出时的尺寸观察与章节切换已经分开处理，防止返回时被拉回上一章节。

状态检查覆盖滚轮上下切章、一次手势只推进一章、导航与主题同步、快速重复点击、首尾边界、减少动态效果、长章节阅读、尺寸变化、详情返回和已保存章节恢复。

浏览器检查覆盖九章的桌面构图、导航定位、键盘双向切换、详情跳转与返回，以及 390 和 320 像素窗口下的排版。滚轮手势由状态检查验证；浏览器自动化的滚动操作只改变外层页面，不能用它证明真实滚轮事件已通过浏览器验证。

此文件记录原型行为。后续 Vue 3 实现应将章节、内容页路由和图片发布配置分别建模；当前尚未连接学校内容管理或业务后端。
