# 官网文化视觉方向 v0.8

日期：2026-10-05。状态：沿用统一的配色、真实学校标识与校方影像；按用户最新意见撤下官网下方装饰，仅保留紧凑的网站信息与链接。图文比例、目录排版及上缘轻量点缀沿用前版。本文件沿用原路径。

## 方向与调整原因

中原文脉 × 现代校园。深蓝是官网的唯一主色，柔和白底承载文字和图文内容。文化表达来自宋体标题、校训、真实校史、书页式分栏，以及留白边角的淡蓝山水与云纹。

首批学校概况单独使用偏黄纸色、印朱、古金、竖排文字和纸纹，与冷白页面及深蓝整屏栏目衔接突兀。本轮将这些独立装饰收束为共用的标题、细线与图片边框，按内容组织章节，避免每个栏目各用一套主题。

本方案用于毕业设计演示，不代表校方官方视觉规范。

## 事实依据

- 学校创建于 1997 年，2008 年升格为本科高校，2014 年更名为郑州工业应用技术学院。依据：[学校机电工程学院公开招聘公告](https://jd.zzuit.edu.cn/info/1081/10579.htm)。
- 校训采用“励学 敦行 明理 至善”。依据：[学校团委招生简章](https://tw.zzuit.edu.cn/info/1001/2832.htm)。
- 学校所在地新郑的地域背景可参考：[新郑市人民政府景区景点介绍](https://www.xinzheng.gov.cn/jqjd.jhtml)。地域历史与学校沿革分别表达。
- 当前校园图片来自[学校招生信息网](https://zsb.zzuit.edu.cn/)与[官网校园风光](https://www.zzuit.edu.cn/gyxy/xyfg.htm)，在图注中保留来源链接；原有生成图保留为历史素材。

## 共用视觉规则

| 元素 | 当前规则 |
| --- | --- |
| 主色 | #244B78，导航、文字标题、年份与链接 |
| 学校标识 | 官网原始校徽、校名题字与英文名称，共用组件，按页面使用深蓝或白色单色呈现 |
| 内容底色 | #F7F7F4，所有文字栏目、详情页、页头与页尾共用 |
| 正文 | #293B4D；辅助文字 #667581 |
| 细线 | #DCE2E5；图片边框 #BAC8D1 |
| 中文标题 | 同一宋体、字号规则、字距与左对齐方式 |
| 图片 | 原始色彩、共用细框与下方说明，保持一致的高度规则 |
| 留白装饰 | 章节上缘保留少量飞鸟、小云纹；下缘不再放置流线、角纹或独立装饰带，页脚仅保留必要文字与链接 |
| 导航 | 保留半透明深蓝与背景模糊；手机展开菜单采用共用白底 |
| 动效 | 沿用既有章节平滑滚动、短程渐显与首页轮播，尊重减少动态效果偏好 |

## 各栏目呈现

- 首页与校园生活使用摄影大图，配合深蓝遮罩和浅色文字；沿用同一导航与标题语言。
- 学校概况、院系专业、教育教学、科学研究、招生就业、合作交流、信息公开统一使用柔和白底与深蓝标题。
- 学校概况保留简介、校区、摄影和 1997／2008／2014 校史节点。
- 院系专业在标题右侧使用两列目录，配以轻量序号和招生资料入口；信息公开在右侧展示已发布内容的标题、摘要与来源类型。手机改为上下排版，目录仍保留两列，长资料允许自然阅读。
- 教学、科研、招生和合作交流共用 .82 : 1.18 的图文比例，列间距由 8% 收紧为 5%，通用图片高度由 240–340px 调整为 280–420px。合作交流使用现有校方校园全景，不虚构合作活动与伙伴。
- 九个官网章节保留共用上缘角纹与侧缘细线，移除下缘角纹。摄影章节以浅色角纹为主，文字章节采用深蓝细线；装饰的尺寸和位置随屏幕调整。
- 学校概况缩短图文与校史间距，时间轴仍保留三个已核验节点。文字章节上缘共享小鸟与淡云，下缘流线已撤下；此前学校概况与合作交流的大幅山水保持移除。装饰只在内容边缘轻微点缀，不覆盖图片或正文。
- 页头在宽屏中部留白使用云纹，小角纹分布在两侧；窄屏移除页头中部插画。页尾与正文共用 #F7F7F4 底色，移除两组装饰 SVG 及其占位高度。
- 内容详情与校园探索保留上缘角纹、云纹与侧缘细线，移除下缘角纹。正文底部间距由桌面 56px／手机 36px 调整为 36px／28px；3D 场景与目录保持清楚可操作。
- 登录页面沿两侧边缘使用浅色／深蓝角纹，表单底角使用小云纹；学生门户、课表、消息、个人资料和管理页共享小角纹与低浓度边角云纹，业务卡片与输入控件保持原有配色和布局。
- 状态页面沿用边缘角纹与底部山水。
- 文化装饰只占据上缘留白和边角。页脚取消建筑、题签、印章及流线和鸟群，保留演示说明、校园探索与学校官方站点两处链接。

## 实现与边界

官网共用配色变量仍定义在 PublicLayout 的 public-site 下。SchoolStory 继承这组变量，标题、链接与图片样式复用官网规则。学生门户继续使用既有业务界面规则，只在外框添加更轻的文化细节。

CulturalOrnament 提供原创山水、云纹、折线角纹与飞鸟，已清理无人引用的流线分支。CulturalFrame 组合角纹与细线形成共用边缘，通过 bottom=false 在官网正文中撤除下缘角纹；门户与登录页保持默认规则。整站放置规则集中在 cultural.css 中；尺寸、色彩和浓度通过 CSS 变量调整。装饰位于内容下方，不接收点击、不进入键盘焦点和读屏内容，没有新增循环动画。山水仅保留在状态页等既有场景，表达抽象文化意象，不对应真实校园地图或学校历史遗迹。手机缩小云纹、侧缘细线隐藏，较长章节保持自然阅读。

上一版建筑长卷 `frontend/src/assets/campus-scroll.svg` 保留为已弃用候选，已取消导入，不进入当前生产构建。用户指出建筑图过于抢眼且与正文割裂，因此当前页脚不再使用整栋建筑或插画分区。

`PublicLayout.vue` 在所有官网页面共享文字页脚，桌面高度 56px；手机按内容自然换为两行。页脚前不再预留装饰区域，并清理相关 CSS。官网章节进度栏移除底部分隔线，避免与页脚上缘重复。

整屏章节浏览保持原有节奏；响应式重排期间暂不将旧滚动位置解释成章节切换，避免阅读长校史后放大窗口跳到下一章。公开目录分别呈现加载、加载失败和暂无内容状态，不再长期显示“加载中”。

校史事实与公开内容接口保持原样。较长章节在手机上允许自然阅读，避免内容裁切。真实资料不足的章节后续补充经过核验的内容，通过内容密度和图文编排完善版面。

## 验证

前端 TypeScript 检查、生产构建与 ESLint 通过。宽屏与手机实测检查章节切换、菜单、图文与校史阅读、详情页返回导航和横向溢出。学校标识与真实影像补充后，核对 1280、390、320px 宽度的官网与门户，验证登录页白色标识及三张校园图切换。最小页面宽度适配浏览器滚动条占用，320px 视口无横向溢出；窄屏门户入口保持单行文字。

文化点缀补充后再次检查 1280、390、320px 官网：装饰不遮盖正文与入口，手机校史可用键盘继续阅读至资料链接，折叠菜单仍可切换章节。以 documentElement.clientWidth 为基准核对横向溢出；矢量装饰均为 aria-hidden、focusable=false、pointer-events:none。
