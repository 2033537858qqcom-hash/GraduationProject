# 官网首页体验检查与优化建议

检查日期：2026-10-18。对象为本项目公开官网，检查了首屏、教育教学、科研、院系章节和手机展开菜单，同时阅读了 PublicHome、PublicLayout、SchoolStory、schoolMedia 及相关样式。以下是优化建议，并非首页重设计的完成记录。

## 方向

保持现代大学官网、学校蓝色、浅暖底色、真实校园影像和轻量国风的方向。继续提供桌面章节浏览；以内容组织和各章节的构图差异增加层次。学校介绍和公开信息放在官网，个人业务留在登录后的门户。

## 当前证据

- 教育教学、科研、招生、合作交流主要沿用左文右图的相同构图，多个章节只有大标题与一句介绍，信息不足以支撑整屏高度。
- 图片库只有四张照片；校园全景用于概况、招生和合作交流，科研章节使用艺术楼外观，图片与主题的关联不足。两张照片原始宽度只有 800px，不适合作为所有大屏场景的主视觉。
- 院系列出六个名称，但每个入口均链接同一个招生站点，缺少学院详情或准确的学院网址。
- 当前没有完整的校园新闻与通知摘要区，通知仅通过底部单条入口出现。
- 手机沿用内部章节滚动区，外层页面也可滚动；菜单展开占据较多阅读空间，需要针对触屏重新安排阅读方式。
- 国风装饰在多个章节重复云纹、飞鸟和边框，其作用应是统一视觉细节，避免为了填空继续增加。

## 建议优先级

| 优先级 | 优化项 | 建议与可验收结果 |
| --- | --- | --- |
| P0 | 内容与链接准确 | 核对院系现名；每个入口对应明确详情或真实站点。公开文章展示日期、栏目和来源；演示内容清晰标记。 |
| P0 | 可用性 | 官网外壳、导航、静态学校介绍可独立呈现；登录或公开内容接口故障在相应模块提示和重试。 |
| P1 | 首页信息密度 | 首屏之后提供校园新闻与公告摘要；采用一张重点新闻和简洁列表组合，保持首页内容为学校公开信息。 |
| P1 | 构图节奏 | 概况使用简介、校史与核实过的数据；院系使用目录；教学突出课堂与实践；科研展示真实成果或活动；校园生活使用纪实图片。详情进入独立页面。 |
| P1 | 主视觉与素材 | 每张轮播有自己的主题与说明；建立按教学、科研、活动、季节分类的真实图片库，提供桌面和手机裁切。 |
| P1 | 手机布局 | 建议自然纵向阅读，保留章节定位；菜单紧凑清晰。核对 390px 手机、短屏和横屏的文字、按钮与图片裁切。 |
| P2 | 字体与国风 | 保留蓝色为主色，宋体用于展示标题、无衬线用于正文；统一边距、细线、图注。减少重复装饰，保留少量云纹、飞鸟等细节。 |
| P2 | 交互统一 | 保留轮播渐变、悬停/聚焦时停止自动轮播及减弱动态偏好；进一步验证触控板、键盘、章节地址和浏览器前进后退的一致性。 |
| P2 | 页脚与辅助入口 | 使用紧凑的校区/到校信息、联系入口与演示标识，延续页面底色。AI 定位为公开导览；三维探索使用预览入口，进入后加载场景。 |
| P2 | 性能与可发现性 | 优先加载首图，后续图片按需加载并压缩；为文章补充独立标题、摘要和分享封面，保持清晰的标题层级和键盘焦点。 |

建议实施顺序：内容与链接核对 → 新闻公告和章节构图 → 图片与排版 → 手机、交互、加载和无障碍验收。

## 外部核对依据

学校当前官网含校园新闻、通知公告、招生、学院介绍和到校指南等内容，并列出学院的独立站点。目前学院目录使用“智能建造学院”，项目内的“建筑工程学院”需要重新核实。

- [郑州工业应用技术学院官网](https://www.zzuit.edu.cn/)
- [W3C 页面结构建议](https://www.w3.org/WAI/tutorials/page-structure/)
- [Google Web Vitals](https://web.dev/articles/vitals)：建议以真实访问的第 75 百分位衡量 LCP ≤ 2.5 秒、INP ≤ 200 毫秒、CLS ≤ 0.1。这里是验收目标，本轮没有进行实网性能测量。

## 同轮前端故障修复

排查复现了场地借用页的 venueCategory、岗位工作台的 taskFilter、请假页的 editing 在初始化之前被导航监听读取，均调整为先初始化再监听。指示条在无选中项时隐藏，并在条件渲染的导航容器重新出现时重新测量。修正两处 lint 错误，以及手机官网网格菜单的选中线错位。

新增真实 Vue 页面 setup 的回归检查，使用客户端监听语义和禁用网络的环境，覆盖 12 个页面；补充指示条消失和容器重建回归。前端全量 123 项测试通过，lint、TypeScript 和生产构建通过；Three.js 已有的大文件构建提示仍存在。
