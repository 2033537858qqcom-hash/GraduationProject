# 宿舍水电预充值验收（2026-11-01）

已实现演示级宿舍预充值：一位在住学生按金额或用量创建订单并付款，同宿舍成员共享到账用量与最近充值记录。室友之间的私下转账不进入平台，不生成按人分摊账单。

## 操作路径

1. 财务经办在“财务收费 → 收费标准”建立水费、电费单价、计量单位和适用校区，由另一位财务复核人员审核生效。
2. 财务经办在“宿舍水电表计”选择房间、表计编号和已审核标准完成绑定。每个房间各一个水表、电表；可调整同类别同计量单位的已审核标准或暂停充值，调整原因留痕。标准变更保留历史订单的价格快照。
3. 学生在“缴费大厅 → 宿舍水电预充值”查看当前宿舍表计。输入金额或用量后先由服务端报价，核对宿舍、金额和到账用量，再创建订单、完成沙箱支付。
4. 支付平台确认后入账一次；室友刷新宿舍信息即可看到共享记录。个人账单和凭证仅归发起订单的人，室友不会收到重复应缴账单。
5. 退款沿用学生申请、财务独立复核流程；退款平台确认后将原充值用量冲正一次，并保留原充值与冲正时间。

## 金额与权限

- 金额以分计算。按用量充值最多三位小数，金额四舍五入到分；按金额充值最多两位小数，到账用量保留九位小数并向下取整。报价不可用、金额不足一分、非普通十进制、负数等均拒绝。
- 新订单重新检查当前入住、房间和楼栋、表计启用状态及已审核标准；价格与报价不一致时要求重新核对。退宿或调宿后不能为原宿舍新发起支付。已经发起的订单仍以原宿舍和价格快照结算，不会充值到新宿舍。
- 查询共享余额和最近50条记录只限当前宿舍；其他房间不能通过指定表计ID访问。只有订单发起人可查看本人详细账单和凭证。
- 请求重放不会重复创建订单；不同室友可以分别充值。账单行锁、原子余额更新和充值入账标记防止重复回调及并发重复入账。退款冲正同样幂等。
- 财务复核可查看表计，只有财务经办可绑定、调整或暂停表计；系统管理员不自动获得财务收费权限。

## 数据与接口

- V37 新增 `dorm_utility_meter` 和 `dorm_utility_recharge`，关联现有房间、已审核标准、付款学生和支付账单。
- 财务：`GET/POST /api/finance/payments/dorm-meters`，`PUT /api/finance/payments/dorm-meters/{id}`。
- 学生：`GET/POST /api/payments/mine/dorm-recharge`，`POST /api/payments/mine/dorm-recharge/quote`；支付和退款继续使用原有个人账单接口。
- 宿舍预充值订单不计入学生必须缴纳的待缴费用概况。

## 当前边界

余额仅是演示账，没有接入学校水电表供应商，也不会自动扣减真实使用量。真实支付宝沙箱支付/通知和真实设备充值仍需实际凭据及供应商接口联调；不能将平台演示到账描述为真实设备到账。本轮未部署远程支付服务。
