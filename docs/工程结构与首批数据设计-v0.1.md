# 工程结构与首批数据设计 v0.1

更新日期：2026-10-04。范围为首个可运行迭代；完整产品仍以需求基线与流程文档为准。

## 工程决策

Spring Boot 按领域拆分的单体应用，Vue 3 + TypeScript + Vue Router 前端。官网、学生门户和工作人员页面拥有不同布局与入口，共享身份和接口层。Three.js 按路由延迟加载，不进入官网首屏脚本。

第一阶段使用 Spring JDBC 显式表达查询归属和状态约束；Flyway 管理数据库版本。后续追加新的迁移，不修改已在数据库中执行的迁移文件。local 使用 H2 文件数据库；mysql 配置已准备。H2 的 MySQL 兼容模式测试不等于 MySQL 实机测试。

## 权限与状态

密码以 BCrypt 哈希存储。浏览器保存 HttpOnly、SameSite=Lax 会话 Cookie，不向 localStorage 写入凭据。写操作使用服务端 CSRF 令牌；登录更新会话 ID 与 CSRF 状态；退出使会话失效。空闲期限 30 分钟。

个人记录所属用户取自认证 principal。消息已读使用“消息 id + 当前用户 id”更新，未归属的记录返回 404。教师的岗位权限不能访问学生门户。

官网草稿只有创建人可以编辑与送审。审核者必须有审核权限，且不是创建人。状态变更同时匹配版本，冲突返回 409；状态更新与审计写入同一事务。公开查询仅返回 PUBLISHED 内容，公开 DTO 排除作者用户标识。

登录节流为单实例内存窗口：同一来源地址与账号 5 分钟内最多 8 次失败；多实例时需共享存储。local 默认初始化演示数据；mysql 默认关闭。当前没有注册、账号维护、重置密码或角色维护页面。

## 接口清单

| 方法与路径 | 用途 / 权限 |
| --- | --- |
| GET /api/health | 数据库健康 |
| GET /api/public/school | 学校与校区 |
| GET /api/public/content?category=notice | 已发布目录，可筛栏目 |
| GET /api/public/content/{slug} | 已发布详情 |
| GET /api/auth/csrf | CSRF 令牌 |
| POST /api/auth/login | 登录 |
| POST /api/auth/logout | 退出 |
| GET /api/me | 本人资料 |
| GET /api/portal/overview | 学生本人资料、课表与消息 |
| POST /api/portal/notices/{id}/read | 本人消息已读，重复操作保留首次阅读时间 |
| GET /api/workbench/overview | 工作人员本人岗位信息 |
| GET /api/admin/content | 编辑或审核权限 |
| POST /api/admin/content | 编辑权限，创建本人草稿 |
| PUT /api/admin/content/{id} | 编辑权限，更新本人草稿及 version |
| POST /api/admin/content/{id}/submit | 编辑权限，送审本人草稿及 version |
| POST /api/admin/content/{id}/publish | 审核权限，发布他人送审内容及 version |

字段以 Java record、Controller 和前端 `types.ts` 为准。正文为纯文本，不执行 HTML；来源链接仅允许有效 HTTP(S) 地址，学校公开资料必须填写来源。尚未实现审核退回、撤稿、发布后修订、富文本或完整内容后台。

## 三维场景边界

四个 `demo-*` 建筑验证交互，不写入真实 building 数据。组件含相机控制、射线选择、目录搜索、介绍、平滑定位、尺寸适配和资源释放。无法创建 WebGL 场景时仍可使用文字目录。

下一步取得可信布局资料，绑定建筑数据库 id、模型节点和公开介绍。真实校区切换、课程地点关联与模型细节后续实现，当前模型不替代整校建模。
