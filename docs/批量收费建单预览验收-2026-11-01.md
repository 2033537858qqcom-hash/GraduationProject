# 批量收费建单预览验收（2026-11-01）

财务经办在“财务收费 → 新建账单”填写多个学生账号后，先预览逐人的校验结果和金额，全部通过后再确认生成草稿。草稿仍按既有流程提交另一位财务人员复核发布。

## 行为

- 最多 100 个不重复学生账号；预览逐行返回学生姓名、金额或不可建单的原因。
- 复用正式建单的学生、收费项目、截止日期、收费依据、金额及收费标准适用范围校验。合计金额只统计通过校验的行，有任意错误时页面不能确认生成草稿。
- 修改任意表单字段会清除预览，必须重新核对；页面也提供“重新预览”。正式生成时服务端再次验证，不把预览结果作为已核准的数据。
- 预览不会创建账单、通知或财务处理记录。正式批量建单沿用请求重试保护和事务：任何学生不再满足条件时，整批失败并回滚。
- 本次沿用手工核定金额和已审核收费标准两种计费方式；没有新增学校实际价格，也没有新增按班级或年级自动选人规则。
