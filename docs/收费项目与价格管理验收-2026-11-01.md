# 收费项目与价格管理验收（2026-11-01）

财务经办可在“财务收费 → 收费项目”新增校服费等项目，并按需要启用或停用；财务复核岗位可以查看项目，收费标准和账单仍须由另一位财务人员独立复核。项目本身不预设价格，也不会直接生成账单。

## 使用流程

1. 财务经办填写项目名称、说明和新增原因。项目名称一经建立即保留，重复名称被拒绝；项目有独立的稳定编码。
2. 在“收费标准”选择项目，填写价格、计价单位、可选校区／专业、生效及截止日期和标准依据，提交另一位财务人员复核。未填写开始或截止日期表示该侧不设日期限制。
3. 审核通过且当前日期在有效期内的标准才能用于新账单或宿舍表计。生效日和截止日均包含当天，以中国标准时间判断。新账单的标准名称、数量和单价在创建时保存为快照。
4. 项目停用后不能用于新标准、新账单或新收费依据。存在启用或待审核标准、未发布账单、待处理依据或启用的宿舍表计时，需要先处理这些事项；“其他费用”保留作为历史兼容项目。
5. 已发布账单不因项目停用而消失或改写，仍可按原项目筛选和查看。已创建的宿舍预充值订单保留创建时的报价；如果表计被停用或用户已离宿，不能再为原宿舍发起新的支付。

不同适用对象可以有多个已审核标准，建单时由经办人员选择；当前没有按学生年级或账期自动匹配价格的规则。价格更改通过创建并复核新标准完成，不直接修改历史订单。

## 权限与数据

- 新增、启用和停用项目需要 `payment:manage`；财务复核和学生不能维护项目。操作保留原因及审计记录。
- 既有八类收费分类保留，分类与历史账单、收费标准仍通过原编码关联。V38 为分类增加启用状态与版本，为价格标准增加可选有效期；旧标准默认不限定日期。
- 业务岗位提交收费依据仍受现有岗位和分类范围约束；新增自定义项目不会自动授予教务、宿管或后勤新的业务权限。
- 学生页面保留有历史账单的已停用项目筛选；没有历史账单的停用项目不再显示。
