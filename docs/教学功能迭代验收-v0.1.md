# 教学功能迭代验收 v0.1

日期：2026-10-05。范围：现有 Java / Vue 3 工程中的首批教学业务闭环。需求关联：FND-03、TCH-01—04、MSG-04、EDU-Q01—03 的首批实现。本文描述实际交付，不表示这些需求的所有扩展和其他校园模块已经完成。

## 已交付

| 用户 | 页面 | 可用功能 |
| --- | --- | --- |
| 学生 | `/portal/learning` | 本人有效教学班、任课教师、已发布课程资料、教学班通知；附件下载 |
| 学生 | `/portal/learning/timetable` | 按学期和周查看本人教学安排，前后周切换；旧 `/portal/timetable` 跳转至此 |
| 学生 | `/portal/learning/grades`、`/portal/learning/exams` | 本人已发布成绩、考试；草稿、撤下和非本人记录不可见 |
| 教师 | `/teaching`、`/teaching/timetable` | 本人授课班级、最小学生名单、本人授课课表；资料草稿、修订、发布、撤下；班级通知 |
| 教务维护岗位 | `/academic` | 建立学期、课程和本学院教学班；添加、停用、恢复授课与成员关系；添加单次课程安排 |
| 教务维护岗位 | `/academic` 的成绩、考试栏目 | 成绩 CSV 模板、读取或粘贴、校验预览、确认保存草稿、逐条发布撤下；考试草稿维护、发布撤下 |

学生门户近期课程已经改为读取教学班及成员关系。旧 `timetable_entry` 表为历史兼容保留，新增教学功能不依赖其中教师姓名匹配授权。

## 演示与使用

访问 `http://127.0.0.1:5173/`，从校园服务入口登录。当前本地后端使用 18080，Vite 通过 `CAMPUS_API_TARGET` 代理；默认工程端口仍为 8080。

| 身份 | 本地演示账号 | 初始访问范围 |
| --- | --- | --- |
| 学生 | `20260001` | Java 教学班与软件工程联合教学班；本人成绩考试 |
| 学生 | `20260002` | 数据库教学班与软件工程联合教学班；本人成绩考试 |
| 教师 | `teacher1001` | Java 与软件工程教学班 |
| 教师 | `teacher1002` | 数据库教学班 |
| 教务信息维护 | `academic1001` | 当前账号所属信息工程学院的教学数据 |

初始密码为 `Demo@2026`。新增账号与教学种子仅在演示初始化开关开启时建立，不覆盖已有密码或重新写入已有教学数据。演示学期为 2026-09-07 至 2027-01-24，课程、课室、成绩、考试和任务均非学校真实业务记录。

普通教师、普通服务人员与系统管理员没有自动获得 `academic:manage`。该权限由独立 `ACADEMIC_STAFF` 角色授予。教学关系和权限在新接口的每次请求中重新查询，不因已登录会话继续沿用失效关系。

## 数据与状态规则

- V3 增加学期、课程、教学班、授课关系、成员、课程安排、资料、班通知、成绩、考试与审计表。行政班依然独立保存在 `class_group`。
- V4 增加数据库写锁，用于协调教学关系撤权与相关写操作，以及课表冲突、考试发布检查；当前实现采用单行事务锁，尚未做高负载容量验证。
- V5 保存课程资料正文、状态与附件的版本快照。历史快照保留在私有表中，当前页面提供现行版本编辑，不提供历史版本恢复界面。
- 资料状态为草稿、已发布、已撤下；编辑已发布资料前先转草稿。修改、上传和状态变化都检查版本。
- 附件目前支持 PDF 与 UTF-8 `.txt`，最大 2 MB；文件内容保存在数据库私有字段，下载验证教学关系与发布状态，使用 attachment、no-store、nosniff。
- 班通知发送到提交时的有效学生名单，每名接收者有独立个人消息。请求标识避免同一次发布重试产生重复通知；目前通知发布后不可编辑或撤下。
- 成绩导入每批最多 500 条，校验成员、范围、精度、重复行与版本。预览不写入成绩；一行无效则整批不保存。更正后转为草稿，保留变更前后值和操作人时间。
- 成绩与考试发布、撤下会发送个人消息；消息不直接展示成绩数值。
- 考试发布重新校验已发布的考场和学生时间冲突；课表新增校验教师、教室和学生时间冲突。
- 教务维护按账号学院限定教学班和可关联人员。暂不支持跨学院授课授权配置；教学班模型与行政班分别管理。

原有 10 项身份、会话、CSRF、内容发布与异常参数测试保留。新增 10 项覆盖：

1. 本人教学班、成绩考试、草稿与非本人数据隔离。
2. 教师、教务、学生、普通服务人员、管理员的岗位权限边界。
3. 资料发布、附件下载、撤下、版本冲突与历史快照。
4. 班通知重试幂等与接收范围。
5. 授课及成员关系停用后的既有会话访问失效。
6. 学期、课程、教学班创建与身份关系校验。
7. 成绩导入整批校验、预览不写入、发布与个人可见性。
8. 考试发布冲突检查及撤下后查询同步。
9. 教务跨学院访问、课表冲突与成绩范围校验。
10. 同一成绩并发发布时一个请求成功、另一个返回冲突，仅产生一次发布审计。

测试使用独立 H2 内存库与真实 Spring Boot HTTP 服务，不调用学校账号或学校教务系统。

## 当前限制与后续工作

- Docker 引擎未运行，MySQL 实例及新迁移的 MySQL 方言联调未完成。本轮运行和测试均使用 H2；不能据此声称 MySQL 已验证。
- 账号、组织、完整岗位授权与离岗交接维护后台尚未实现；本轮教务界面使用已有账号和学院目录。
- 课表目前支持单次安排新增及查询，完整模板导入、批次修改、调停课流程尚未实现。
- 考试采用单场安排的手工维护，尚无批量考试导入、座位分配或监考流程。成绩录入由教务演示维护岗位负责，未新增教师改分权限。
- 通知版本修订、接收名单管理、阅读统计和撤下尚未实现；同班有效学生可查看当前班级通知。
- 课程资料目前仅支持 PDF 与文本附件，历史版本保留但没有恢复界面；附件容量治理与对象存储未接入。
- 完整服务目录、我的事务、请假证明、报修、住宿、预约、活动、社团及 Agent 尚待后续开发。
- Vite 对已有 Three.js 分块仍提示超过 500 kB；未完成性能、兼容性、压力或生产部署验证。

下一业务迭代可基于教学和身份关系推进服务目录、学生请假／证明、对应岗位处理、本人事务和待办。现有教学查询接口也为后续 Agent 本人查询提供业务基础，Agent 尚未接入。
