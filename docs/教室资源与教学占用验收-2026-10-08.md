# 教室资源与教学占用验收

验收日期：2026-10-08（Asia/Shanghai）。对象：当前 Java / Vue 工程，使用 H2 集成测试和隔离浏览器环境。本轮完成教室目录与课程、考试的资源关联；学校真实教室资产尚未接入。

## 交付范围

管理员首页和导航新增“教室资源目录”，入口为 `/admin/resources`。教务页面的课程、考试表单从该目录选择地点，服务端按资源 ID 取得校区和教室名称。

| 功能 | 实际行为 |
| --- | --- |
| 目录建档与维护 | 校区、资源编号、名称、楼栋、房间号、可选楼层、教室类型、教学容量和考试容量；两种容量为 1—1000 人，考试容量不得超过教学容量 |
| 查询与分页 | 按名称、编号、楼栋搜索，按校区、类型、启停及可安排资格筛选；目录、未来占用、修改历史分别分页 |
| 启停与追溯 | 新建、修改、启用和停用均填写原因；保留操作者、时间、版本及资料变化，无物理删除入口 |
| 教学关联 | 单次课程和考试草稿提交 `roomId`；服务端派生地点，禁止依靠自由文本声明一个新的教室 |
| 容量检查 | 课程按教学容量、考试按考试容量检查有效教学班成员数；草稿保存和考试发布分别校验 |
| 占用检查 | 课程与已发布考试按同一资源 ID 共用冲突校验；学生、教师及教学班冲突检查继续生效，相邻时段允许衔接 |
| 操作保护 | 乐观版本检查、共享教学事务锁、未保存输入离开提示、请求失败保留输入；筛选、所选记录、详情栏目及分页进入 URL，刷新可恢复 |
| 窄屏布局 | 筛选和编辑字段收为单列，表格在自身容器内滚动，按钮与确认框继续使用现有校园门户样式 |

管理员沿用 `foundation:manage` 管理资源，教务岗位沿用 `academic:manage` 读取资源并维护本学院教学信息。普通教师、学生、服务人员没有资源维护权限；管理员也不会因此获得教学、成绩或考试维护权限。每次请求继续检查当前账号和岗位权限。

## 使用规则

只有启用且楼栋、房间号、两种容量齐全的教室可新增安排。前端展示完整地点、用途容量与状态，并禁选容量不足的选项；服务端再次检查，不能通过改请求绕过。教学班人数按有效成员关系计数，账号暂时停用不释放该关系的座位。

尚未结束的课程与已发布考试占用资源，未发布草稿不占用时段。停用有上述占用的资源会返回冲突；缩减容量后无法容纳其中任一教学班，也会拒绝整次修改。新增或恢复教学班成员时同时重查既有安排的学生冲突与已知教室容量。

考试草稿可能在保存后遇到教室停用、人数变化或新占用，发布时重新核查；失败不改变状态和通知。撤下已发布考试可以释放其占用，不要求该资源仍可新排。仅有历史安排的资源可停用，原学习查询继续保留。

已经被教学引用的资源不能移动校区、变更编号或修改已确定的楼栋房间；历史迁移条目允许补录原本未知的楼栋和房间。名称、楼层、类型和容量可以在约束内修改。旧课表与考试保留当时的地点文字，重命名不改变资源 ID，也不能绕开同一资源的时间冲突。

资源维护、成员启用、课程新增和考试发布使用同一数据库教学写锁，避免“检查时空闲、提交时已停用”或并发超容量。资源版本改变后，旧编辑请求返回 409，操作记录不会产生半次修改。

## 数据迁移与演示边界

Flyway V8 新建 `classroom_resource`、`room_audit`，为既有课程和考试增加 `room_id` 外键。按旧记录的“校区＋精确教室文字”导入，保留原文字和未知资料；不同文字不根据猜测自动合并。已有教学、内容和个人数据保持原记录。

原开发库已从 V7 成功迁移到 V8，共导入 **6 条待补录资源**。其楼栋、房间和容量没有从名称推测或填造，已有课表仍可查询，新增课程和考试须先补录或选择已建档资源。历史未知容量不会追溯阻断已有学生关系；新安排须使用完整资料。

迁移前已停止文件库进程并备份到 `artifacts/room-resources-2026-10-08/campus-before-v8.mv.db`。备份含本地账号数据，只作本机恢复用途。主库健康检查、迁移版本、资源统计及公开内容读取结果见[主库检查](../artifacts/room-resources-2026-10-08/main-smoke.json)。

空库初始化另建 3 间明确标记为 DEMO 的演示教室，不代表学校实际楼栋、位置或容量。空库考试示例时段避开其示例课程；初始化不会重写既有库的安排。目录尚未绑定 Three.js 建筑，也未引入任何未经核实的校内资产信息。

课程与考试写接口现要求 `roomId`，旧自由文本写请求须调整；旧数据和学生查询接口继续保留地点文字。测试中的自定义地点通过测试专用资源 fixture 建档，生产接口不会按文字自动创建资源。
