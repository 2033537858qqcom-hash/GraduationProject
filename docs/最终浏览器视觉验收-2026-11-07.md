# 最终浏览器视觉验收

- 日期：2026-11-07
- 版本：307 字子集 / 260 项测试
- 环境：用户现有 Chrome 与正在运行的 `5173` 开发环境；复用现有演示会话。未启动另一套服务、未注入前端接口数据。
- 范围：官网首屏及换图、登录、门户、三维独立沙盘、高德地图路线 HUD；桌面窗口与 390px 窄屏。

## 1. 视觉结论

官网两张首屏影像的标题对比、登录分区、门户欢迎区和校园照片的比例均可保留。本轮没有放大字体或重排这些已认可的画面。

实机检查发现并修复了两处校园探索窄屏问题：

| 问题 | 修复前 | 修复后 |
| --- | --- | --- |
| 地点目录挤压画布 | 390px 下仍为两列，画布约 15.2px、目录 302px | 单列，画布约 337.2px，目录位于画布下方 |
| 高德路线 HUD 压住缩放控件 | 路线 HUD 与缩放控件发生交叠 | 两者不重叠，实测净距约 12.7px |

独立沙盘的导览条和缩放按钮也已通过普通页面操作检查，没有交叠。

## 2. 根因与改动

校园探索主题从全局样式拆出后，在页面加载时晚于 `campus-assistant.css`。主题文件里的桌面网格规则覆盖了仍留在全局文件中的窄屏规则。由于第一列允许收缩到 0，页面没有横向溢出，先前只检查溢出无法发现画布已被挤成细条。

本轮将校园探索的 1100 / 850 / 760 / 600px 响应式规则移入 `campus-explore-theme.css` 尾部，和桌面主题保持同一归属与正确层叠顺序。窄屏标题、工具栏及目录间距一起恢复。

工具栏保持单行标签；窄屏“建筑沙盘”按钮只显示图标，原 `aria-label` 和提示名称保留。路线 HUD 底部偏移从 58px 调为 84px，为双缩放按钮、底边距和间隙留出空间。

本轮没有新增字面色值、`!important` 或小字号声明。

## 3. 金线规则定案

金线继续只用于办事流程页和恢复入口。Learning / Notices / Foundation / Finance / Workbench 保留素页头，不铺满全站。

流程页金线为每页一条 35px 短线；官网、登录保留已认可的品牌处理。按钮、状态和卡片不增加金色装饰。本轮不进行大规模字面色迁移。

## 4. 验证结果

- 可见 Chrome 中完成了官网换图、登录、门户以及校园探索的普通页面检查。
- 实际打开高德地图、图书馆路线 HUD、独立三维沙盘与地点导览。
- 390px 修复后画布和目录均为约 337.2px 宽，目录在画布下方；地图 HUD 不再覆盖缩放控件。
- 恢复浏览器默认视口后，桌面实际宽度 1440px，画布约 960.2px、目录 302px，无横向溢出。
- `pnpm build`（含类型检查）、`pnpm lint`、`pnpm check:design` 均通过，测试 260/260 通过。
- 设计预算保持：颜色字面量 1376、`!important` 116、小字号字面量声明 100。
- 最终生产字体 preload 继续指向存在的哈希资源，字体仍为 307 字。

一次单页原始 CDP 视口权限申请被拒绝后，已停止该方式，未重试或更换通道绕过。随后只使用普通页面操作、截图和撤销已有的临时视口设置。测试结束时已关闭临时登录检查标签，并恢复浏览器默认视口。

这属于桌面 Chrome 和窄屏视口验收，不代表实体手机硬件、Windows 不同缩放设置或全业务流程已经验收。
