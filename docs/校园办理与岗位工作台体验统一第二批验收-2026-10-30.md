# 校园办理与岗位工作台体验统一 · 第二批

日期：2026-10-30（Asia/Shanghai）。接续第一批门户框架，范围为请假、证明、报修、调宿、预约、统一办事记录及岗位工作台。

## 实现

- 办理页统一标题、筛选、资料字段、材料区域、处理意见、表单操作与历史记录样式，沿用暖白和深绿。请假与证明编辑页增加资料分组，退回后编辑时直接展示本次补交意见。
- 新增只读办理路径提示。各业务使用各自真实状态名称；请假批准与待销假、报修待验收、床位待入住、预约同意及使用中均不会显示为已完成。拒绝、撤回、取消、过期不标成所有步骤成功；未知状态保留待核对提示。
- 报修保留原有详细进度条和按权限显示的操作区，只在编辑时增加填写说明。调宿的取消待处理提示与已取消分开。具体操作仍由原接口、资格校验和 allowedActions 控制，路径提示不授予权限。
- 统一办事页沿用真实数量、筛选、分页及时间线，调整概况、列表和展开进度的视觉层级。
- 工作台突出当前工作空间、岗位职责与申请人／范围／状态／日期，优化待办列表和移动端布局。数量仍汇总当前账号全部已授权岗位，来源失败仍显示结果不完整。增加工作台刷新与初次加载失败后的重试，并阻止离开页面后旧响应写回。
- 预约申请改为原生模态 dialog，支持焦点限制、Escape、关闭后恢复焦点及原有未保存保护。下拉选项打开时，Escape 先关闭下拉，不同时退出表单。
- 修复顶部工具栏遮挡普通弹层的问题，以及表单自动定位时标题被遮挡、窄屏搜索按钮挤压、320px 资源卡片溢出；保留打印和系统减少动态效果方案。

## 验证

- 前端 **188 项测试通过**，新增 7 项办理路径回归，覆盖各领域状态、尚未完成的后续阶段、退回后的不同身份提示、关闭／过期状态、未知状态、取消待处理及未选择记录的空状态。
- TypeScript 与生产构建通过。ESLint 无错误，保留 ManagedPasswordReset.vue 原有换行警告；Three.js 仍有已有大文件提示。
- 浏览器检查桌面 1440px、手机 390px 的证明、调宿、预约与报修填写页面；预约目录和模态表单额外检查 320px，修正后页面无横向溢出，表单内部宽度与可用宽度一致。
- 验证预约弹层真实处于 `:modal`，下拉与表单分别响应 Escape、关闭恢复发起按钮焦点；输入测试文字后退出先确认，“继续编辑”保留文字，“放弃并离开”结束测试输入，未保存预约。
- 验证辅导员工作台切换岗位、刷新和待办跳转；学生统一办事页能展开实际处理时间线。
- 最终检查的浏览器错误日志为空。没有重新验收后端全量或 MySQL 环境，本批未修改后端实现与数据库迁移。
