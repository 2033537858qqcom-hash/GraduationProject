# 校园门户体验统一 · 第一批

日期：2026-10-30（Asia/Shanghai）。范围：登录页、登录后公共框架、学生首页。

## 页面调整

- 登录页沿用真实校园影像，采用暖白、深绿与中文衬线标题；保留会话过期、改密提示、错误反馈、登录回跳与演示账号说明，增加可切换的密码可见性。
- 公共框架采用桌面侧栏，按实际权限分为我的校园、岗位办理、基础管理及账号服务，空组不显示。学生兼具工作人员权限时同时保留相关入口，管理员身份不自动获得业务审核入口。
- 手机导航使用原生模态抽屉：打开聚焦当前栏目，锁住背景滚动；Escape、关闭按钮或导航后恢复滚动；切回桌面关闭抽屉，卸载清理监听与滚动锁定。
- 学生首页先展示校园欢迎区、日程／未读消息／办事快捷入口及四类常用服务，再显示近期课程、两条个人消息预览和完整服务目录。保留分类、搜索、空结果清除与完整消息页入口，服务分类采用可按下的筛选按钮语义。
- 首页复用既有 overview 数据，不新增统计接口，不将未读数描述为待审批数量。常用入口按当前资料中的权限显示。
- 新样式限定在 `.campus-portal` 和 `.campus-login`，保留其他业务页的信息结构和语义状态。包含窄屏、系统减少动态效果及打印侧栏隐藏样式。

## 验证

- 前端 181 项测试通过，包括新增 6 项导航回归：学生、管理员、多岗位组合、单项岗位能力、具体路由及别名定位、错误前缀不误匹配。
- TypeScript 与生产构建通过。ESLint 无错误；保留原有 ManagedPasswordReset.vue 表单换行警告与 Three.js 大文件构建提示。
- 浏览器以本地演示学生和管理员验证正常登录、密码显隐、退出、未登录请假入口转到登录并在登录后返回、服务搜索及清空、课表跳转、请假页栏目定位、管理员配置入口。
- 桌面 1440px、中等宽度 1100px、手机 390px 和 320px 检查页面宽度；验证抽屉聚焦、Escape、背景滚动恢复及切回桌面关闭。
- 使用既有隔离预览数据库 `artifacts/cinema-preview/campus` 与 18090 → 18080 预览实例；仅验证查询、导航与登录，没有创建或提交业务申请。
