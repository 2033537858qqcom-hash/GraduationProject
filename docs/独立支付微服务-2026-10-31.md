# 独立支付宝沙箱支付微服务（pay-service）

- 代码：`pay-service/`（Spring Boot 3.5 + JDK17 + 官方 alipay-sdk-java，H2 文件库，`-Xmx256m`）。
- 主后端渠道：`PAYMENT_CHANNEL=ijpay`（默认，原进程内电脑网站支付）或 `remote`（调用 pay-service 当面付扫码）。
- **remote 渠道配置（线上，2026-10-31 已部署 HTTPS）**：
  - `PAYMENT_ENABLED=true`
  - `PAYMENT_CHANNEL=remote`
  - `PAYMENT_REMOTE_URL=https://pay.研途学堂.cn`（punycode 等价：`https://pay.xn--ckst2fk89agjv.cn`）
  - `PAYMENT_REMOTE_TOKEN=<与 pay-service PAY_INTERNAL_TOKEN 相同>`
- **异步通知**：`https://pay.研途学堂.cn/api/alipay/notify`（服务器 `.env` 的 `ALIPAY_NOTIFY_URL`）。
- **域名与证书**：`pay.研途学堂.cn` DNS A → `124.220.12.254`；主域已 ICP 备案；Let's Encrypt（certbot）；需放行 TCP 80/443。
- 金额始终由主后端从 `payment_bill.amount_cents` 计算；前端拿到 `qrCode` 后本地生成二维码，每 3 秒轮询 `GET /api/payments/mine/{id}`，主后端在未支付时向 pay-service 同步状态并校验金额。
- 内部调用签名：`hex(HMAC_SHA256(token, METHOD\nPATH\nTIMESTAMP\nNONCE\nBODY))`，±5 分钟、nonce 防重放。
- 部署细节与 nginx/compose 见 `pay-service/README.md`、`pay-service/deploy/`。
