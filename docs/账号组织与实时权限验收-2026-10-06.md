# 账号、组织与实时权限验收

日期：2026-10-06。范围：本地 Java / Vue 工程的首批基础管理，修复检查记录中的 F04。人员资料均为毕业设计演示数据，未接入学校真实业务系统。

## 可用功能与入口

使用本地演示管理员 `admin` 登录，初始密码为 `Demo@2026`。从管理员首页或导航进入 **账号与组织管理**，地址为 `/admin/foundation`。

| 栏目 | 本轮交付 |
| --- | --- |
| 账号与岗位 | 按姓名、账号、学工号、身份、组织和状态筛选；分页查询；受控建档；修改姓名、学工号、校区、学院和行政班；分配既有身份与岗位；启用、停用 |
| 组织目录 | 学院与管理部门、专业、行政班的建档和修改；学院→专业→行政班关系校验；有关联时限制跨组织迁移 |
| 修改记录 | 操作人员、时间、变更前后资料及原因；按记录类型或具体账号／组织筛选；分页查询 |
| 编辑体验 | 完整业务名称和岗位职责；必要字段及错误提示；未保存内容离开确认；密码不回显、不进入草稿存储；窄屏表单调整 |

行政班与教学班分别维护：学生在基础管理中归属行政班，在教务模块中关联具体课程的教学班。

账号登录名创建后不可修改；学工号保持唯一。初始密码使用 BCrypt 保存，至少十位并包含字母、数字，UTF-8 编码最多 72 字节。密码和密码摘要不出现在列表、修改记录或接口响应中。

## 权限与业务约束

- 基础管理需要 `foundation:manage`，仅系统管理员拥有。学生、教师、教务、服务人员、编辑及审核人员不能访问。
- 复用七种已有身份。界面展示岗位名称、职责和权限说明；本轮不支持任意新建角色或编辑权限定义。
- 教务限定所属学院，教师限定有效授课教学班，学生限定本人。管理员身份没有自动取得教学维护权限；已有官网编辑审核权限仍按原规则执行，禁止自审。
- 学生必须分配行政班，班级必须属于所选学院；非学生身份不能携带行政班。学生、教师、教务归属学院，不能分配到管理部门。
- 人员仍有有效教学关系时，不能直接变更学院。建班、教学关系维护与人员转学院共用教学写锁，避免并发产生跨学院关系。
- 学院有关联专业、教学班或师生时不能改为管理部门；专业关联行政班、行政班关联账号时，不能直接更换所属关系。
- 编辑采用版本校验，旧版本返回 409；事务失败不会留下部分角色分配或成功修改记录。基础管理写操作串行校验当前操作者，防止已被停用的管理员继续提交等待中的操作。
- 禁止当前管理员停用自己或移除自己的管理员身份；移除或停用其他管理员时，至少保留一名启用的管理员。账号停用保留历史，不提供删除人员入口。

每次请求在 URL 和方法权限判断前重新读取账号状态及当前角色权限。账号停用、角色或校区／学院／班级归属变更会增加会话版本，旧会话再次访问时失效；账号重新启用也不会恢复旧会话。仅修改姓名、学工号时保持会话，并读取新资料。

这里的“即时失效”指**变更提交后的下一次服务端校验**，不是主动推送关闭其他浏览器，也不承诺取消已经执行完成的请求。页面导航会重新读取本人身份；业务接口返回 401 时清理前端登录态与本人教学草稿。
