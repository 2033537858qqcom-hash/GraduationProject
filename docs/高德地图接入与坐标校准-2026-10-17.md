# 高德地图接入与坐标校准

本阶段为东校区校园探索接入高德 JS API 2.0。实景模式提供卫星／标准底图、地点目录定位、可开关的 Three.js 立体建筑、俯视和缩放；保留独立校园沙盘及网络失败时的切换入口。未新增数据库表或修改业务数据。

## 本地配置与部署

在 `frontend/.env.local` 配置 `VITE_AMAP_KEY` 和 `AMAP_SECURITY_JSCODE`，格式见 `frontend/.env.example`。前者是浏览器使用的 Web 端标识；后者只由 Vite 开发／预览服务器读取，通过固定的 `/_AMapService` 代理加到上游请求中。配置文件已被 Git 忽略，本文不记录真实凭据。配置变更后重启前端服务。

代理只接受 GET／HEAD，固定访问高德的样式和 REST 服务域名，覆盖传入的 jscode，并移除校园登录 Cookie、Authorization 及 CSRF 请求头和上游 Set-Cookie。`window._AMapSecurityConfig.serviceHost` 在 SDK 脚本加载前设置。

正式静态部署需要同源反向代理。`infra/nginx/amap-service.conf.template` 提供待接入站点 server 块的模板；使用部署环境中的安全密钥替换唯一的 `${AMAP_SECURITY_JSCODE}` 占位符。使用 envsubst 时必须指定该变量名，避免替换 `$args` 等 Nginx 变量。生成配置应放在仓库外，并按部署镜像确认 CA 证书路径，执行 `nginx -t` 后再启用。模板未在本机 Nginx 实例上执行，当前实测的是 Vite 开发代理。

参考高德官方[安全密钥代理说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)、[自定义图层与相机同步示例](https://developer.amap.com/demo/javascript-api-v2/example/selflayer/glcustom-layer)、[地图容器坐标转换](https://lbs.amap.com/api/maps-javascript-api/reference/amap-map/map)。

## 坐标证据

原有模型使用留存卫星截图的像素坐标。浏览器地图 URL 的 geoobj 是视窗范围，不能当作图片四角经纬度。模型继续沿用已有图片配准，通过三处图片参照点拟合到 GCJ-02；立体图层进一步在高德 customCoords 投影坐标中拟合，避免把纬度角度直接当作模型米数。

初次小尺度人工辨认未通过独立检查，已弃用。最终将留存高清截图与当前 JS API 的可见卫星截图做 SIFT 特征匹配，用 RANSAC 相似变换计算同名像素，再在开发校准界面读取对应的高德坐标。该图像分析只使用本地留存截图，不调用未授权地图接口，也不作为项目运行依赖。

## 渲染与限制

高德自定义图层可能提供 WebGL 1，而项目当前 Three.js 需要 WebGL 2，因此使用独立透明画布，并在 GLCustomLayer 的渲染回调中同步官方 customCoords 相机。高德继续管理底图和交互，Three.js 管理自己的上下文。高分屏同时约束画布的 CSS 尺寸和绘制尺寸，避免 DPR 导致建筑放大错位；切换模式时释放图层、几何、材质、观察器和上下文。

地图叠加模式不绘制沙盘底座、道路、水面和草地。原有分布图核对的楼名、静逸楼／锦绣餐厅分区、内院孔洞均保留。H1、H2等未确认楼体仍是符号，建筑高度仍为展示值。

图片残差、坐标小数位和独立检查均不能证明测绘精度。原始截图的屋顶视差、早期图片配准、卫星影像时效、楼体概化和非实测高度仍会带来偏差；本阶段没有获得精细建筑模型、室内数据、实测楼层或可用于步行导航的入口数据。

最终静逸楼独立检查点与三点配准预测位置相差约 1.35 米。这是当次影像配准的一处检查结果，不代表全校范围的位置精度承诺。

## 验证范围

新增回归覆盖固定代理域名、服务端密钥覆盖、校园登录信息隔离、方法限制、缺失配置、SDK 去重与重试、坐标变换、独立检查点、移动端总览取景、地图叠加不含沙盘底座。另运行既有校园轮廓与分区检查、类型检查、ESLint 和前端构建。浏览器验证结果及最终截图在任务完成时一并记录。

最终验证：92 项前端测试全部通过；`pnpm lint`、`pnpm build`、`pnpm check:campus` 通过。校园几何检查仍为 31 处地点、47 个轮廓要素、38 个根网格、7,204 个三角形。构建仍有校园页面 Three.js 分块超过 500 kB 的提示，构建成功。

浏览器已验证卫星／标准底图、日景／暮色、立体建筑、俯视、静逸楼／锦绣餐厅分别定位和关联切换，以及地图／沙盘连续切换。独立验证标签页未记录到控制台错误或警告；沙盘模式只保留一个沙盘画布，返回地图后只保留一个地图宿主和一个独立建筑画布。375×812 断点下页面内容宽度与 clientWidth 均为 360，无横向溢出；总览随可用画布尺寸重新取景，手动探索后保留用户视角。

最终截图为同目录下 `verified-overview.jpg`、`verified-jingyi-top.jpg`、`verified-standard-night.jpg`、`verified-mobile.jpg`。安全密钥未进入前端构建产物；本地环境文件被 Git 忽略。
